# Work Programme 2025 — topics


# Open Internet Stack and NGI-style topics

* [HORIZON-CL4-2025-03-DATA-11 — Open Internet Stack: development of technological commons/open-source 3C building blocks (RIA)](horizon-cl4-2025-03-data-11.md) - The founding Open Internet Stack topic: one EUR 10M RIA (budget-based, up to 70% FSTP, max EUR 400k per third party) to build an open-source commons stack feeding the 3C telco-edge-cloud pilot; deadline 2 Oct 2025, closed, funded the NLnet-led Restack project.
* [HORIZON-CL4-2025-03-HUMAN-16 — Drive the evolution of the internet towards open and interoperable Web 4.0 and Virtual Worlds: building blocks in priority areas (RIA) (Virtual Worlds Partnership)](horizon-cl4-2025-03-human-16.md) - NGI-style open-source building-block topic in the Virtual Worlds Partnership: EUR 14.5M RIA, EUR 1–3M per project across five areas (EUDI identity, software supply chain, open hardware, alternatives to centralised platforms, Web 4.0 demos), FSTP up to 15% / EUR 150k; deadline 2 Oct 2025, closed, 4 projects funded.

# Adjacent topics

* [HORIZON-CL4-2025-03-DATA-08 — Large-scale pilots for supply end-to-end infrastructures integrating device, network computing and communication capabilities for Telco Edge Cloud deployments, as a basis for Connected Collaborative Computing Networks (3C networks) (RIA)](horizon-cl4-2025-03-data-08.md) - Adjacent (not OIS-branded) WP 2025 topic: the EUR 75M 3C telco-edge-cloud supply-side large-scale pilot (one RIA, restricted eligibility, TRL 3→7) that the Open Internet Stack topic DATA-11 must feed with open building blocks; deadline 2 Oct 2025, closed, funded EURO-3C.
* [HORIZON-CL4-2025-03-HUMAN-17 — Specific support for the Virtual Worlds Partnership and the Web 4.0 initiative (CSA) (Virtual Worlds Partnership)](horizon-cl4-2025-03-human-17.md) - Adjacent WP 2025 CSA (EUR 2.5M, one project) to launch the Virtual Worlds Partnership and write the Virtual Worlds and Web 4.0 SRIAs, incl. a Web 4.0 architectural framework built on open-source commons; deadline 2 Oct 2025, closed, funded NOVA.
