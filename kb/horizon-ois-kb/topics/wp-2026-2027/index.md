# Work Programme 2026-2027 — topics


# Open Internet Stack topics

* [HORIZON-CL4-2026-04-DATA-02 — Open Internet Stack Sovereign Solutions (RIA)](horizon-cl4-2026-04-data-02.md) - Main WP 2026-2027 Open Internet Stack topic: EUR 20.5M RIA (EUR 7–10.25M per project) for deployable open-source sovereign solutions in networking, operating systems/firmware and software supply chain, FSTP up to 80% / EUR 400k; deadline 15 Apr 2026, closed, 3 proposals retained from 31.
* [HORIZON-CL4-2026-04-DATA-03 — Open Internet Stack Support for Scale (CSA)](horizon-cl4-2026-04-data-03.md) - EUR 4M lump-sum CSA (one project) to run the Open Internet Stack hub: cataloguing, security/accessibility audits, branding, training, sustainability advice and a policy/compliance sandbox; deadline 15 Apr 2026, closed, 1 proposal retained from 6.
* [HORIZON-CL4-2026-04-HUMAN-02 — Web 4.0 architectural framework and Open Internet Stack applications for virtual worlds (RIA)](horizon-cl4-2026-04-human-02.md) - EUR 16.8M RIA (EUR 2.8–8.4M per project, 3 expected) for one Web 4.0 'Architectural Framework' project (FSTP up to 70%) and open-source decentralised 'Applications' for virtual worlds (FSTP up to 20%), max EUR 300k per third party; deadline 15 Apr 2026, closed, 2 retained from 32.

# Adjacent / not OIS (2027 call)

* [HORIZON-CL4-2027-04-DATA-08 — Demand-side 3C pilot demonstrators on converged Telco Edge Cloud Infrastructure (IA)](horizon-cl4-2027-04-data-08.md) - Adjacent (not OIS-branded) forthcoming topic: EUR 38M IA, ~EUR 19M per pilot, 2 pilots (mobility + one other vertical) on the 3C telco-edge-cloud infrastructure, expected to use Open Internet Stack components; TRL 6-8, restricted eligibility; opens 17 Nov 2026, deadline 18 Mar 2027.
* [HORIZON-CL4-2027-04-HUMAN-01 — Advanced and Innovative hardware components for Virtual Worlds (RIA) (Virtual Worlds Partnership)](horizon-cl4-2027-04-human-01.md) - NOT an Open Internet Stack topic (often confused with one): EUR 39M RIA for XR/haptics/BCI hardware, EUR 4.8–5.6M per project, ~8 projects, TRL 3→5, Virtual Worlds Partnership; opens 17 Nov 2026, deadline 18 Mar 2027.
