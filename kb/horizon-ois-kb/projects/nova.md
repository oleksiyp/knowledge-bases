# Summary
NOVA is a 36-month CSA (1 May 2026 – 30 Apr 2029, EU contribution €2,546,117.50) under HORIZON-CL4-2025-03-HUMAN-17 "Specific support for the Virtual Worlds Partnership and the Web 4.0 initiative", coordinated by PNO Innovation (ES) with 22 beneficiaries including the Virtual Worlds Association, Fraunhofer, imec, CNRS, SAP and Siemens[^cordis]. It is included here because it sets the Web 4.0 agenda that HUMAN-16 projects and Restack plug into[^cordis].

# Objectives
- Launch and operationalise the European Partnership on Virtual Worlds and support the Web 4.0 initiative[^cordis].
- Produce two Strategic Research and Innovation Agendas (Virtual Worlds; Web 4.0), a Virtual Worlds roadmap, a Web 4.0 implementation agenda and an SME/start-up competitiveness blueprint[^cordis].
- Deliver policy recommendations, programming input for future funding and a European standardisation strategy[^cordis].
