# Summary
NGI TrustChain is a 39-month RIA (1 Jan 2023 – 31 Mar 2026, EU contribution €10,609,150) under HORIZON-CL4-2022-HUMAN-01-03 — the same topic as NGI0 Core — coordinated by European Dynamics Luxembourg with F6S, University of Ljubljana, AUEB, Fundación Cibervoluntarios, Alastria, Timelex and the University of Athens[^cordis].

# Objectives
- Create a portfolio of NGI protocols and decentralised software for trustworthy digital identity, secure data pathways, data economics and energy-efficient storage/sharing[^cordis].
- Run five open calls: decentralised identity; user privacy and data governance; economics and democracy; multi-chain support for NGI protocols; green scalable DLTs[^cordis].
