# Summary

NGI Zero Core is grant **101092990** under HORIZON-CL4-2022-HUMAN-01-03, running 1 January 2023 –
31 December 2026 with an EU contribution of about €11.5M.[^cordis-core] It set aside **€8.8M** for
€5k–€50k grants to core internet technology.[^nlnet-core] **The 8th and final call closed on 1 October
2024.**[^nlnet-core]
