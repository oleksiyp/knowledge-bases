# Databases projects

* [PostgreSQL](postgresql.md) - The community-governed relational database that became the default substrate of the AI-agent era; PG 18 async I/O, $1B+ of Postgres M&A, thin maintainer funding.
* [Supabase](supabase.md) - Open-source Postgres backend platform that went from a $2B to a $10.5B+ valuation as the default database of AI coding tools; acquired Turso (Oct 2026).
* [Neon](neon.md) - Serverless Postgres acquired by Databricks (~$1B, May 2025) and rebuilt as Lakebase; public repo nearly silent since Aug 2025.
* [ClickHouse](clickhouse.md) - Apache-2.0 OLAP database; company valued ~$15B (Jan 2026), rolling up open-source AI and observability tools and adding managed Postgres.
* [DuckDB](duckdb.md) - MIT in-process analytics DB under the DuckDB Foundation; DuckLake 1.0, v2.0 preview; AWS acquired DuckLabs (Aug 2026).
* [Turso (libSQL and Turso Database)](turso.md) - SQLite fork plus Rust rewrite, now also speaking Postgres; company joining Supabase (Oct 2026).
* [TimescaleDB (Tiger Data)](timescaledb.md) - Postgres time-series extension; company rebranded Tiger Data (June 2025) to sell general Postgres.
* [ParadeDB](paradedb.md) - AGPL Postgres search extension; $12M Series A (July 2025), pre-1.0.
* [OrioleDB](orioledb.md) - Supabase-owned next-generation Postgres storage engine, still in beta.
* [Xata](xata.md) - Postgres branching platform open-sourced under Apache-2.0 (Apr 2026) for developers and coding agents.
* [MySQL](mysql.md) - Oracle-owned database in a stewardship crisis: layoffs, silent repo, OurSQL Foundation, advisory governance pledge.
* [MariaDB](mariadb.md) - PE-owned MySQL fork on an acquisition spree (Galera, SkySQL, GridGain); Galera removal attempt reversed.
* [Vitess (and PlanetScale)](vitess.md) - CNCF MySQL sharding; sponsor PlanetScale pivots to Postgres (Metal, Postgres GA, Neki).
* [MongoDB](mongodb.md) - SSPL document DB; business re-accelerated to 30% growth, but two CEO changes in 11 months and a lawsuit against FerretDB.
* [CockroachDB](cockroachdb.md) - Distributed SQL that retired Core (2024) and took development private (Sept 2026), citing AI risk.
* [TiDB](tidb.md) - Apache-2.0 MySQL-compatible distributed SQL; agent-focused cloud; OurSQL co-founder.
* [YugabyteDB](yugabytedb.md) - Open Postgres-compatible distributed SQL; per-agent Postgres; record H1 2026.
* [SurrealDB](surrealdb.md) - BSL multi-model database pitched as agent memory; 3.0 GA plus $23M (Feb 2026).
* [Gel (formerly EdgeDB)](gel.md) - Graph-relational layer on Postgres; team joined Vercel, cloud shut down, repo dormant.
* [Convex](convex.md) - FSL-licensed reactive backend database; $24M round and 10x growth from AI app builders.
* [InfluxDB 3](influxdb.md) - Rust and Arrow time-series DB; v3 Core GA as MIT/Apache open source (Apr 2025).
* [QuestDB](questdb.md) - Apache-2.0 time-series DB; 10.0 with QWP streaming protocol (Aug 2026).
* [ScyllaDB](scylladb.md) - Cassandra-compatible NoSQL that ended its AGPL line for source-available (Dec 2024).
* [Apache Cassandra](cassandra.md) - ASF wide-column DB; 6.0 alpha brings Accord ACID transactions.
* [Dragonfly (with KeyDB and Garnet)](dragonfly.md) - BSL Redis-compatible store, 2.0 shipped; KeyDB abandoned; Microsoft Garnet active.
* [Milvus](milvus.md) - LF AI & Data vector database; 3.0 lake-native vector search (July 2026).
* [Qdrant](qdrant.md) - Rust Apache-2.0 vector engine; $50M Series B (Mar 2026).
* [Weaviate](weaviate.md) - BSD vector database with fast releases; no priced round since 2023.
* [Chroma](chroma.md) - Apache-2.0 embedding DB; Chroma Cloud GA, release cadence slowed in 2026.
* [LanceDB (Lance format)](lancedb.md) - Multimodal lakehouse DB and format; $30M Series A, SDK 1.0.
* [StarRocks](starrocks.md) - LF-hosted MPP analytics; sponsor CelerData rebranded PhoenixAI (May 2026).
* [Apache Doris](apache-doris.md) - ASF real-time analytics DB with steady 4.1.x releases.
