# AI Agents, LLM Frameworks & Coding Tools projects

* [Agent2Agent (A2A) Protocol](a2a-protocol.md) - Google-originated open protocol for agent-to-agent discovery and delegation; absorbed IBM's competing ACP, shipped v1.0 in March 2026 and joined MCP inside the Agentic AI Foundation in August 2026 — a successful consolidation, though real-world usage lags MCP.
* [AG2 (formerly AutoGen community fork)](ag2.md) - Community fork of AutoGen v0.2 launched Nov 2024 by original AutoGen creators; survived and shipped 1.0 in July 2026, but remains small (~5k stars on the new repo) next to the 61k-star original.
* [AGENTS.md](agents-md.md) - A plain-markdown convention for giving coding agents project instructions, published by OpenAI and collaborators in August 2025 and donated to the Agentic AI Foundation in December 2025; a lightweight, widely-adopted standard.
* [Aider](aider.md) - Pioneering terminal AI pair-programmer (Apache-2.0, ~49k stars) that effectively stalled — last release v0.86.0 in Aug 2025 and last commit May 2026 — as funded terminal agents (Claude Code, Codex CLI, Gemini CLI, OpenCode) overtook it.
* [Microsoft AutoGen](autogen.md) - Microsoft Research's pioneering multi-agent framework; split by the AG2 community fork in Nov 2024, then superseded by Microsoft Agent Framework and put into maintenance mode (community-managed, no new features) — a high-star project retired by its sponsor.
* [AutoGPT](autogpt.md) - The 2023 viral autonomous-agent repo (~188k stars) that re-licensed its new platform code under the non-open Polyform Shield license; still actively developed as a beta agent platform, but long overtaken in relevance.
* [Browser Use (and Stagehand)](browser-use.md) - MIT library that lets LLM agents drive a web browser; grew from a weekend HN launch to ~117k stars and a $17M seed (Mar 2025). Peer Stagehand (Browserbase, MIT, ~25.5k stars) underpins Browserbase's $40M Series B (Jun 2025).
* [Cline](cline.md) - The original open-source autonomous coding agent for VS Code (Apache-2.0); outlived its own forks (Roo Code shut down), raised $32M in 2025 and reports 11M users in 2026 while expanding to CLI, SDK and a desktop app for open-weight models.
* [Composio](composio.md) - MIT SDK and hosted platform giving agents authenticated access to hundreds of third-party tools (MCP-compatible); raised a $25M Lightspeed-led Series A in July 2025 ($29M total raised) and grew to ~30k stars.
* [Continue](continue.md) - Apache-2.0 open-source AI coding assistant for VS Code/JetBrains that pivoted messaging toward CLI agents, "Mission Control" and code-quality checks for AI-generated code; still active (v2.0 in June 2026) but losing relative mindshare.
* [CrewAI](crewai.md) - MIT-licensed role-based multi-agent framework (~59k stars) that reached 1.0 in Oct 2025 and monetizes via the CrewAI AMP enterprise platform; one of the most adopted independent agent frameworks.
* [Dify](dify.md) - LLM-app/agentic-workflow platform from LangGenius under a modified Apache-2.0 (no multi-tenant use, logo retention); ~158k GitHub stars and a $30M Series Pre-A in March 2026 — big community, modest funding.
* [DSPy](dspy.md) - Stanford NLP's MIT-licensed framework for "programming, not prompting" LLMs with optimizers; academic-governed and steadily growing (3.0 in Aug 2025, ~38.5k stars).
* [Flowise](flowise.md) - Visual low-code LLM/agent builder (Apache-2.0, ~55k stars) acquired by Workday in Aug 2025 and then sunset — code freeze 2026-07-29, repo archived Aug 2026, end of life 2026-08-31 — with the team blaming coding agents for making rigid low-code workflows obsolete.
* [Gemini CLI (and Google ADK)](gemini-cli.md) - Google's Apache-2.0 terminal agent (launched June 2025 with a generous free tier) and its Agent Development Kit (April 2025); both grew fast on Google's distribution — Gemini CLI to ~107k stars, ADK to ~22k.
* [goose](goose.md) - Block's local-first, Rust-based general-purpose AI agent (desktop, CLI, API); donated to the Linux Foundation's Agentic AI Foundation in Dec 2025 and now lives at github.com/aaif-goose — a healthy corporate-to-foundation handoff.
* [Haystack](haystack.md) - deepset's Apache-2.0 LLM/RAG orchestration framework; steady, enterprise-oriented and still shipping (Haystack 3.0 in July 2026, ~26.6k stars), but no longer a mindshare leader.
* [Kilo Code](kilo-code.md) - Open-source coding agent (VS Code/JetBrains extension, CLI, Slack bot) forked from Roo/Cline lineage and co-founded with ex-GitLab CEO Sid Sijbrandij; raised $8M in Dec 2025 and was acquired by Anaconda in July 2026 — fast build-and-flip outcome.
* [LangChain / LangGraph](langchain.md) - The incumbent LLM-app and agent framework (LangChain + LangGraph, MIT); survived the 2024 "abstraction backlash" by shipping 1.0 releases and turning LangSmith into a commercial agent-engineering platform, making LangChain Inc an AI-tooling unicorn.
* [Langflow](langflow.md) - MIT-licensed visual agent/RAG builder acquired by DataStax (Apr 2024) and carried into IBM when IBM closed its DataStax acquisition (May 2025); ~155k stars and still actively released — the low-code builder that survived inside big tech.
* [Letta (formerly MemGPT)](letta.md) - Apache-2.0 stateful-agent platform from the MemGPT researchers; repositioned in 2025–26 around "Letta Code" (a memory-first coding agent) as the core server's release cadence slowed (last tagged server release May 2026).
* [LlamaIndex](llamaindex.md) - MIT-licensed RAG/agent framework (~52k stars) whose company pivoted from general RAG toward "agentic document workflows" (LlamaParse, LlamaExtract, LlamaCloud), with strategic investment from Databricks and KPMG in 2025.
* [Mem0](mem0.md) - Apache-2.0 memory layer for AI agents; raised $24M (Seed + Series A, Oct 2025) on fast API growth and reached ~66k stars — the leading OSS "agent memory" project.
* [Microsoft Agent Framework (and Semantic Kernel)](microsoft-agent-framework.md) - Microsoft's MIT-licensed Python/.NET agent framework unifying AutoGen and Semantic Kernel ideas; reached 1.0 on 2026-04-02 with A2A/MCP interop, consolidating Microsoft's fragmented agent OSS.
* [Model Context Protocol (MCP)](model-context-protocol.md) - Anthropic's open protocol for connecting models to tools and data; went from launch (Nov 2024) to universal industry standard adopted by OpenAI, Google and Microsoft, and was donated to the Linux Foundation's Agentic AI Foundation in Dec 2025 — the clearest protocol success of the period, shadowed by a steady stream of security issues.
* [n8n](n8n.md) - Fair-code (Sustainable Use License) workflow-automation platform that reinvented itself as an AI-agent orchestrator; the biggest business winner in the domain — valuation went from ~€250M (Mar 2025) to $2.5B (Oct 2025) to $5.2B (SAP, May 2026) with ~206k GitHub stars.
* [OpenAI Agents SDK](openai-agents-sdk.md) - OpenAI's lightweight MIT-licensed multi-agent framework (successor to the experimental Swarm), launched March 2025; quickly became a top-tier framework (~30k stars) and a direct competitor to LangChain/CrewAI.
* [OpenAI Codex CLI](openai-codex-cli.md) - OpenAI's open-source (Apache-2.0) terminal coding agent, released April 2025 and later rewritten in Rust; a lab-backed OSS client to a proprietary model service that reached ~128k GitHub stars.
* [OpenClaw (formerly Clawdbot / Moltbot)](openclaw.md) - Self-hosted, always-on personal AI agent driven via WhatsApp/Telegram/Slack; the breakout OSS phenomenon of 2026 (≈391k GitHub stars, most-starred software repo) whose creator joined OpenAI while the project moved to a foundation — but also the year's biggest agent-security cautionary tale.
* [OpenCode](opencode.md) - Open-source, provider-agnostic terminal coding agent from the SST team (now Anomaly); the breakout coding-agent OSS project of 2025–26, reaching ~211k GitHub stars and becoming the main open alternative to Claude Code.
* [OpenHands (formerly OpenDevin)](openhands.md) - MIT-licensed autonomous software-engineering agent platform from All Hands AI (now branded OpenHands); ~90k stars, 1.0 in Dec 2025 and a 2026 push into enterprise governance — a solid open alternative to Devin.
* [OpenManus](openmanus.md) - MIT open-source clone of the Manus general agent built in days in March 2025 (~58k stars); a hype spike whose last tagged release was v0.3.0 in April 2025.
* [Pydantic AI (and Logfire)](pydantic-ai.md) - Type-safe MIT agent framework from the Pydantic team (v1 Sep 2025, ~20k stars) paired with the commercial Logfire observability platform — a "validation library to agent platform" open-core playbook backed by a $12.5M Sequoia-led Series A (Oct 2024).
* [Roo Code](roo-code.md) - Popular Cline fork turned standalone VS Code coding agent; its company shut the extension down and archived the repo on 2026-05-15 to pivot to the cloud agent Roomote, declaring "IDEs are not the future of coding" — the period's starkest OSS shutdown-by-pivot.
* [smolagents](smolagents.md) - Hugging Face's minimalist Apache-2.0 "code agents" library (1.0 on 2024-12-31, ~29.7k stars); popular but release cadence slowed in 2026 (last release May 2026).
* [SWE-agent](swe-agent.md) - Princeton/Stanford academic coding agent (MIT, ~20.5k stars) tied to SWE-bench research; still maintained but with no tagged release since May 2025 — influential research artifact rather than a product.
* [Void (open-source Cursor alternative)](void-editor.md) - YC-backed open-source VS Code fork positioned as an open Cursor alternative; development paused after Aug 2025 and the repo was deprecated and archived in 2026 — a casualty of the AI-IDE fork economy.
* [Zed](zed.md) - Rust-built, GPL/AGPL/Apache-licensed code editor from Atom's creators that bet on AI agents and real-time collaboration; raised a $32M Sequoia-led Series B (Aug 2025), shipped Windows (Oct 2025) and 1.0 (Apr 2026), while its AI push spawned a no-AI fork (Gram).
