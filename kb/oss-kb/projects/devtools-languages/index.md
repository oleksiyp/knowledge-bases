# Developer Tools & Languages projects

* [Angular](angular.md) - Google's enterprise TypeScript framework; completed a signals-first, zoneless re-architecture (zoneless default in v21, Nov 2025; Signal Forms and Angular Aria stable in v22, June 2026) and staged a credible "renaissance" while staying single-vendor.
* [Astro](astro.md) - Content-first, islands-architecture web framework; its VC-funded company shut its Studio DB service (2024–25), then was acquired by Cloudflare (2026-01-16) and has since shipped Astro 6 (Mar 2026) and Astro 7 with a Rust compiler (Jun 2026) — an OSS success whose business exited by acquisition.
* [Bazel (and Buck2)](bazel.md) - Google's Apache-2.0 polyglot build system; Bazel 9 LTS (Jan 2026) removed WORKSPACE and finished moving rules out of core, and a user-funded BUILD Foundation (Linux Foundation directed fund, announced at BazelCon 2025) now pays for community rulesets; Meta's Buck2 still has no stable release.
* [Bevy](bevy.md) - Data-driven Rust game engine (ECS) run by the nonprofit Bevy Foundation; shipped five releases (0.15–0.19) on a ~4–5-month cadence with 0.20 in RC, crates.io downloads rose to 6.6M+, but it remains "drastically underfunded" and still lacks an upstream editor.
* [Biome](biome.md) - Community-governed Rust formatter/linter for JS/TS/CSS/GraphQL (successor to Rome); shipped v2 with type-aware linting and GritQL plugins, absorbed GritQL (Dec 2025) and passed 500 lint rules (v2.5, June 2026) on sponsorship funding — but now faces VoidZero/Cloudflare's Oxlint/Oxfmt.
* [Bun](bun.md) - All-in-one JavaScript/TypeScript runtime, bundler, test runner and package manager; went from zero-revenue VC startup to Anthropic-owned infrastructure for Claude Code (Dec 2025) and was rewritten from Zig to Rust with AI in May 2026.
* [CPython (Python)](cpython.md) - The reference Python implementation, stewarded by the Python Software Foundation; technically thriving (free-threading officially supported in 3.14, lazy imports and faster JIT in 3.15) while the PSF navigated a funding squeeze, rejecting a $1.5M NSF grant over anti-DEI terms and then receiving $1.5M from Anthropic.
* [Deno](deno.md) - Secure-by-default JavaScript/TypeScript runtime from Node.js creator Ryan Dahl; the runtime keeps shipping (2.7–2.9 in 2026) but Deno Land Inc. hit layoffs in March 2026, shut Deploy Classic, and its JSR/Deploy bets have underdelivered.
* [Electron](electron.md) - OpenJS Foundation framework for Chromium+Node desktop apps; the incumbent behind VS Code, Slack, Discord and most AI desktop clients, stable on an 8-week cadence (Electron 38→44 in 2025–26) but dogged by a macOS Tahoe system-lag bug (Sept 2025) and recurring CVEs.
* [Elixir](elixir.md) - Apache-2.0 functional language on the Erlang VM; added a gradual set-theoretic type system without breaking the language. v1.20 (2026-06-03) infers types for all constructs, and its competing language servers merged into the official Expert LSP (2026).
* [Expo](expo.md) - MIT-licensed React Native framework and toolchain whose company monetizes cloud build/update services (EAS); became React Native's de facto default, went New-Architecture-only in SDK 55 (Feb 2026) and raised a $45M Series B with an AI "Expo Agent" (Apr 2026) — the healthiest open-core business in this domain.
* [Flutter](flutter.md) - Google's BSD-licensed cross-platform UI toolkit (with Dart); survived 2024 layoffs and the Flock community fork (Oct 2024, now dormant) by shipping steadily and offloading — Canonical became steward of Flutter desktop (May 2026) and Material/Cupertino left the core SDK (3.47, Aug 2026).
* [Forgejo (and Codeberg)](forgejo.md) - Community hard fork of Gitea (GPL since Aug 2024) that powers the nonprofit forge Codeberg; the main beneficiary of the 2025–26 "leave GitHub" wave driven by Copilot pushes and GitHub's absorption into Microsoft (Zig, Dillo, Gentoo, Fedora).
* [Ghostty](ghostty.md) - Fast, native, Zig-written terminal emulator by Mitchell Hashimoto; MIT-licensed, became a non-profit project under Hack Club's 501(c)(3) fiscal sponsorship on 2025-12-03 — a deliberate anti-VC model for developer infrastructure.
* [GitButler](gitbutler.md) - Git client from GitHub co-founder Scott Chacon built around stacked/virtual branches and an agent-friendly `but` CLI; Fair Source (FSL), not OSI open source; raised a $17M a16z-led Series A in April 2026.
* [GitHub (platform)](github.md) - Microsoft-owned home of most open source; commercially booming on Copilot (4.7M paid subscribers, Jan 2026) but lost its independence when CEO Thomas Dohmke left and GitHub was folded into Microsoft CoreAI (Aug 2025), then suffered an AI-traffic reliability crisis, a self-hosted-runner pricing reversal, AI-slop PR floods and a May 2026 breach of ~3,800 internal repos.
* [GitLab Community Edition](gitlab-ce.md) - The MIT-licensed open-core base of GitLab, the main self-hostable alternative to GitHub; the codebase keeps shipping monthly (GitLab 19.0, May 2026) but the company's energy goes into paid AI (Duo Agent Platform, credits) while GitLab Inc. decelerates and cut ~14% of staff in June 2026.
* [Gleam](gleam.md) - Statically typed, Apache-2.0 functional language for the Erlang VM and JavaScript; a breakout small language of 2024–26. It went from v1.0 (Mar 2024) to v1.18 (Jul 2026), was Stack Overflow 2025's second most admired language and held its first conference, all funded by sponsors.
* [Go](go.md) - Google-led, BSD-licensed language that stayed stable and thriving under new tech lead Austin Clements. It made the Green Tea GC the default (1.26), added generic methods and json/v2 (1.27, Aug 2026) and got an official MCP SDK, but dropped work on new error-handling syntax.
* [Godot Engine](godot.md) - MIT-licensed game engine stewarded by the Godot Foundation; four feature releases (4.4–4.7) in 18 months and marquee adoptions such as Slay the Spire 2 cement it as the leading open alternative to Unity/Unreal.
* [Homebrew](homebrew.md) - The volunteer-run macOS/Linux package manager under the Open Source Collective; shipped 5.0 in November 2025 with concurrent downloads by default and official Linux ARM64 support — stable, unglamorous, no business.
* [Java / OpenJDK](openjdk.md) - Oracle-led reference Java (GPLv2 with Classpath Exception); technically steady through JDK 25 LTS, 26 and 27. Oracle's per-employee licensing and audits push companies to the free Temurin builds (600M+ downloads) and to Azul, now majority-owned by Thoma Bravo (Nov 2025).
* [Jujutsu (jj)](jujutsu.md) - Git-compatible VCS started at Google; monthly releases (0.34 → 0.45, Oct 2025–Sept 2026), GA inside Google, first JJ Con (2026), and its creator became CTO of jj-native hosting startup East River Source Control.
* [Kotlin](kotlin.md) - JetBrains' Apache-2.0 language for the JVM and multiple platforms, thriving in 2024–26. Compose Multiplatform for iOS went stable (May 2025), 2.4 stabilised context parameters, and JetBrains shipped a free Kotlin LSP plus a paid IntelliJ LSP for VS Code/Cursor (Aug 2026).
* [Ladybird](ladybird.md) - Independent, from-scratch web browser engine run by the nonprofit Ladybird Browser Initiative; donor-funded (Cloudflare, Shopify, FUTO, Proton, 37signals), adopting Rust with AI assistance, and in June 2026 closed public pull requests ahead of its first alpha.
* [Laravel](laravel.md) - The most popular PHP framework, whose company Laravel Inc. took its first-ever VC round ($57M Series A from Accel, Sept 2024) to build Laravel Cloud; shipped Cloud (Feb 2025), Laravel 12/13 and Nightwatch, and Otwell says 2026 Cloud revenue is on pace to grow 5x — a rare clean OSS-to-PaaS success so far.
* [mise](mise.md) - MIT Rust tool-version, env and task manager by Jeff Dickey; ~34.5k stars and a top-10 Homebrew formula; went from ~$600/month to a sponsored full-time job in 2026 (Entire as title sponsor, Omarchy's Omacom Foundation as premier sponsor).
* [Mojo](mojo.md) - Modular's Python-superset language for AI/GPU programming; went from proprietary compiler to Mojo 1.0 (Aug 2026) and an Apache-2.0 open-sourced compiler (2026-08-18), backed by a $250M round at $1.6B (Sept 2025).
* [Neovim](neovim.md) - Community-run, Apache-2.0 Vim fork; steadily shipping (0.11, 0.12.x through Aug 2026), passed 100k GitHub stars, and remained Stack Overflow's most admired development environment for a fifth year in 2025.
* [Next.js](nextjs.md) - Vercel's React meta-framework; commercially the strongest framework franchise (Vercel valued at $9.3B in Sept 2025) but hit by two critical security incidents — the middleware auth bypass (CVE-2025-29927) and the exploited React2Shell RCE (Dec 2025).
* [Node.js](nodejs.md) - The incumbent server-side JavaScript runtime under the OpenJS Foundation; absorbed competitors' best ideas (native TypeScript execution) and in 2026 moved to one major release per year — stable, foundation-governed, no business entity at risk.
* [npm (registry and CLI)](npm-registry.md) - GitHub-owned JavaScript package registry and CLI; the epicenter of the period's supply-chain attacks (chalk/debug phishing and the Shai-Hulud worm in Sept 2025, Shai-Hulud variants through 2026), forcing a hardening of tokens, 2FA and trusted publishing.
* [Nx](nx.md) - MIT monorepo build system from Nrwl, monetized via Nx Cloud; steady 6-month majors (21, 22, 23) and AI self-healing CI, but compromised twice — the s1ngularity npm attack (Aug 2025) and a backdoored Nx Console extension that led to GitHub's internal-repo breach (May 2026) — plus a reversed paid-cache licensing move.
* [Open VSX Registry](open-vsx.md) - Eclipse Foundation's vendor-neutral VS Code extension registry; became critical infrastructure for VS Code forks (Cursor, Windsurf, etc.) and AI editors, then suffered repeated supply-chain incidents (token leaks, GlassWorm) and launched a paid Managed Registry in April 2026.
* [PHP (and the PHP Foundation)](php.md) - The web's most-deployed server language, now sustained by the PHP Foundation's paid core developers; shipped PHP 8.4 and 8.5 (pipe operator) on schedule and adopted FrankenPHP, but the Foundation's sponsor count fell sharply in 2025 and it spent ~$139k more than it raised.
* [Pixi (prefix.dev)](pixi.md) - BSD-3 Rust package manager on the conda ecosystem; growing in robotics, science and CUDA work (Pixi Build, Pixi Audit in 2026), and its company sells conda channel hosting (GA April 2026).
* [React Router / Remix](react-router.md) - Shopify-backed routing library and full-stack framework; Remix v2 merged into React Router v7 (Nov 2024) and Remix 3 split off as a React-free framework (announced May 2025), with React Router v8 released June 2026.
* [React](react.md) - The dominant UI library; moved from Meta control to the vendor-neutral React Foundation under the Linux Foundation (announced Oct 2025, launched Feb 2026) while suffering its worst-ever vulnerability, the CVSS-10 React2Shell RCE in Server Components.
* [Rspack](rspack.md) - ByteDance's webpack-compatible Rust bundler; on a disciplined bi-monthly cadence from 1.0 (2024) to 2.0 (Apr 2026) and 2.2 (Aug 2026), with Next.js integration — the corporate-funded counterpart to VoidZero's Rolldown.
* [Ruby on Rails](rails.md) - DHH's full-stack Ruby web framework, backed by the Rails Foundation; technically steady (Rails 8.0/8.1 'No PaaS required', Rails World 2026 its largest yet) but culturally contested — the 'Plan Vert' fork call against DHH (Sept 2025), the end of RailsConf, the RubyGems crisis, and DHH's own HEY backend moving to Rust (Sept 2026).
* [Ruby, RubyGems and Bundler](rubygems.md) - The Ruby language and its package toolchain; Ruby itself is healthy (Ruby 4.0 with ZJIT and Ruby::Box, Dec 2025) but the Sept 2025 Ruby Central seizure of the RubyGems/Bundler repos split the maintainer community, spawned the gem.coop fork, moved stewardship to Ruby core and left Ruby Central in 'real financial jeopardy' by April 2026.
* [Rust](rust.md) - Memory-safe systems language governed by the Rust Project with the Rust Foundation; in 2025–26 it lost its "experimental" tag in the Linux kernel, entered the TIOBE top 10 (July 2026), and became the default language for rewrites of developer tooling — including AI-driven ones.
* [Servo](servo.md) - Rust browser engine originally from Mozilla, revived in 2023 under Linux Foundation Europe with Igalia doing most of the work; slow but real progress, culminating in a first versioned release (0.0.1) in October 2025.
* [Svelte / SvelteKit](svelte.md) - Compiler-first UI framework and its full-stack meta-framework; Svelte 5 (runes, Oct 2024) rewrote the core, and SvelteKit's type-safe remote functions (2025–26) lead into the SvelteKit 3 release candidate (Aug 2026) — community-governed with creator Rich Harris paid by Vercel.
* [Swift](swift.md) - Apple-led open-source language that pushed well beyond Apple platforms in 2025–26 — a Swift SDK for Android (Oct 2025), Java interop and new workgroups — with Swift 6.4 released in Sept 2026.
* [Tauri](tauri.md) - Rust + system-webview framework for small, secure desktop and mobile apps; Tauri 2.0 (Oct 2024) added iOS/Android, 2.12 and the first 3.0 alphas shipped in Sept 2026 — while its commercial partner CrabNebula made its paid cloud free and moved community services into a foundation (June 2026).
* [Turborepo](turborepo.md) - Vercel-owned MIT Rust monorepo task runner; steady quarterly 2.x releases (2.4 → 2.11) including a 96% faster 2.9 built with AI agents, while creator Jared Palmer left Vercel in Oct 2025.
* [TypeScript](typescript.md) - Microsoft's typed superset of JavaScript; executed the decade's most consequential compiler rewrite — a native Go port (Project Corsa) announced March 2025 and shipped as TypeScript 7.0 on 2026-07-08 with ~8–12x faster builds.
* [uv, Ruff and ty (Astral toolchain)](uv.md) - Astral's Rust-built Python toolchain — uv (package/project manager), Ruff (linter/formatter) and ty (type checker) — the biggest Python tooling success of the decade, whose VC-backed company was acquired by OpenAI in March 2026 before its pyx registry business got going.
* [Vite (and the VoidZero toolchain — Rolldown, Oxc, Vitest, Vite+)](vite.md) - The dominant frontend build tool and its Rust-powered siblings; VoidZero raised $17M, abandoned a paid Vite+ license for MIT, shipped Vite 8 on Rolldown and Vite+ 1.0, and was acquired by Cloudflare in June 2026.
* [Vue.js and Nuxt](vue.md) - Evan You's community-funded UI framework and its Nuxt meta-framework; Vue stays a stable #2/#3 framework with Vapor Mode (no virtual DOM) reaching RC in July 2026, while Nuxt's company NuxtLabs was acquired by Vercel (July 2025) and Evan You's VoidZero by Cloudflare (June 2026).
* [Zed](zed.md) - GPU-accelerated Rust code editor from the Atom creators; raised a $32M Sequoia-led Series B (Aug 2025), shipped Windows (Oct 2025) and 1.0 (Apr 2026), and is building a business on AI usage billing, Zed for Business and DeltaDB — while a no-AI fork (Gram) appeared.
* [Zig](zig.md) - Systems language run by the nonprofit Zig Software Foundation; left GitHub for Codeberg in Nov 2025 citing decline and AI pushes, holds a strict no-LLM contribution policy, shipped 0.15/0.16 — and lost its flagship user Bun to Rust in 2026.
