# Security & Sustainability projects

* [Alpha-Omega](alpha-omega.md) - Linux Foundation directed fund (>$7M/yr) paying for security work in critical OSS; in 2026 became the conduit for AI-lab money to help maintainers triage AI-discovered vulnerabilities and seeded Akrites.
* [Anubis](anubis.md) - MIT-licensed proof-of-work 'AI firewall' by Xe Iaso (Techaro) that OSS forges and sites adopted en masse in 2025 to survive AI-scraper floods; a breakout defensive success (~23k stars).
* [bcachefs](bcachefs.md) - Copy-on-write Linux filesystem by Kent Overstreet; merged in 6.7 (Jan 2024), then removed from mainline in 6.18 (Sep 2025) after process and conduct disputes — now shipped as an out-of-tree DKMS module.
* [curl](curl.md) - Ubiquitous transfer library maintained largely by Daniel Stenberg; the bellwether for AI-slop vulnerability reports — ended its bug bounty (Jan 2026) and paused vuln intake for July 2026, while continuing to ship releases.
* [CVE Program](cve-program.md) - The MITRE-operated, CISA-funded global vulnerability ID system; nearly lapsed in April 2025, spawning the CVE Foundation, EUVD and GCVE as hedges, before CISA moved funding to a protected budget line in early 2026.
* [EU Cyber Resilience Act (CRA)](eu-cyber-resilience-act.md) - EU regulation imposing security obligations on products with digital elements, with a light-touch 'open-source steward' role; reporting obligations for manufacturers went live on 2026-09-11 via ENISA's Single Reporting Platform.
* [GitHub Secure Open Source Fund](github-secure-open-source-fund.md) - GitHub-run program (announced Nov 2024) giving maintainers $10k plus a 3-week security education cohort; multi-sponsor, 70+ projects funded; a modest but well-structured success.
* [Kubernetes ingress-nginx](ingress-nginx.md) - Once the default Kubernetes ingress controller; retired by SIG Network (announced Nov 2025, best-effort maintenance ended March 2026) because too few maintainers could keep it secure — the highest-profile 'retired for lack of maintainers' case.
* [libxml2](libxml2.md) - Core XML library in browsers and OSes, effectively maintained by one volunteer; in May 2025 its maintainer abandoned security embargoes and stepped back from libxslt, a landmark protest against unpaid security labor.
* [npm registry (security posture)](npm-registry.md) - The JavaScript package registry run by GitHub/Microsoft; the epicenter of OSS supply-chain attacks 2025-2026 (chalk/debug, Shai-Hulud waves, axios, TanStack, keyv), forcing the biggest security-default overhaul in its history (classic tokens revoked, trusted publishing, npm 12 install scripts off).
* [National Vulnerability Database (NVD)](nvd.md) - NIST's CVE enrichment database; never cleared its 2024 backlog and in April 2026 formally abandoned universal enrichment for a risk-based model — a structural decline of a public security good.
* [Open Source Pledge](open-source-pledge.md) - Sentry-initiated pledge asking companies to pay $2,000 per employed developer per year to OSS maintainers; ~$7.4M pledged cumulatively — a meaningful norm-setting effort that remains small relative to need.
* [Open VSX Registry](open-vsx.md) - Eclipse Foundation's vendor-neutral VS Code extension registry that became critical infrastructure for AI IDE forks; repeatedly abused by GlassWorm malware (2025-2026) while launching a paid Managed Registry (Apr 2026).
* [Opengrep](opengrep.md) - Community fork of Semgrep CE created by a consortium of AppSec vendors after Semgrep moved key engine features behind commercial licensing (Dec 2024-Jan 2025); a vendor-backed 'defensive fork' that is active but niche.
* [OpenSSF (Open Source Security Foundation)](openssf.md) - Linux Foundation's open source security umbrella (Sigstore, Scorecard, SLSA, Alpha-Omega sibling); grew into the de facto coordinator of AI-era vulnerability response with $12.5M AI-triage grants, Akrites and a registry-sustainability pledge in 2026.
* [PyPI (Python Package Index) security posture](pypi.md) - Python's package registry, run by the PSF; a trusted-publishing pioneer that still took a major hit in the TeamPCP LiteLLM compromise (Mar 2026) and responded with stricter release-immutability rules; stable but under-funded.
* [Rust for Linux](rust-for-linux.md) - Effort to add Rust to the Linux kernel; survived bruising maintainer conflicts and resignations (Asahi lead Hector Martin, Feb 2025) to be declared no longer experimental in Dec 2025.
* [Sovereign Tech Agency (Germany)](sovereign-tech-agency.md) - German federal agency funding open digital infrastructure (Fund, Resilience, Fellowship, Standards, Challenge); the leading public-sector model for paying maintainers, cited as template for an EU Sovereign Tech Fund.
* [Trivy](trivy.md) - Aqua Security's widely used open source vulnerability scanner; became the entry point of the TeamPCP campaign (Feb-Mar 2026) — a security tool turned supply-chain weapon that cascaded into LiteLLM and beyond.
* [XZ Utils](xz-utils.md) - Compression library whose 2024 multi-year social-engineering backdoor (CVE-2024-3094) became the reference case for maintainer-takeover risk; fixed quickly, but backdoored artifacts lingered in Docker Hub images into 2025.
