# Summary
Observable built a beloved but niche product — reactive JavaScript notebooks for visualization — and has spent 2024–2026 searching for a durable business: Observable Framework (open-source static data apps, Feb 2024), Canvases (proprietary collaborative whiteboards with "verifiable AI", 2025), and finally a rewritten, agent-first Observable built on the open Notebook Kit format, made default on 2026-09-01[^obs-2][^obs-2025][^official-new]. The community openly questioned its direction and pricing changes in 2025[^where-going]. Last disclosed funding was a $35.6M Series B in 2021[^tt-funding].

# Monetization model
SaaS subscriptions for teams (private notebooks, database connectors, scheduling, Canvases); open-source runtime, Plot, Framework and Notebook Kit under ISC.

# Successes
- Strong brand among visualization practitioners; open file format finally adopted (Notebook Kit).

# Failures / risks
- Repeated pivots, pricing churn and a stalled Framework project weakened trust[^where-going]; no funding disclosed since 2021.
