# Summary
Meta announced the React Foundation on 2025-10-07. It takes over React, React Native and supporting projects such as JSX, along with their infrastructure (GitHub, CI, trademarks), React Conf, and ecosystem grants. Seth Webster is executive director, and the founding corporate members are Amazon, Callstack, Expo, Meta, Microsoft, Software Mansion and Vercel.[^react-foundation-blog] A vendor-neutral board governs the foundation, while a separate technical governance structure set by contributors aims to stop any one company from dominating.[^react-foundation-blog] The foundation officially launched on 2026-02-24, when Meta contributed the React project.[^wiki-react]
