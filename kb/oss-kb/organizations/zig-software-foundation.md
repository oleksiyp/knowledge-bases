# Summary
The ZSF pays Zig core developers from donations and corporate sponsorships.[^wiki-zig] On 2025-11-26 it moved the Zig repository to Codeberg and called GitHub Sponsors "a liability", asking donors to move recurring donations to Every.org.[^zig-codeberg] Mitchell Hashimoto pledged an additional $400,000 on 2026-06-21.[^wiki-zig] It enforces a strict no-LLM contribution policy.[^zig-codeberg]
