# Summary
The Rust Foundation funds infrastructure, security and maintainers for the Rust Project. OpenAI joined as a member in June 2026, and CodSpeed, Haevek, Perplexity and Software Stewardship Lab joined in September 2026.[^wiki-rust][^rf-media] Programs include the Rust Foundation Maintainers Fund (Maintainer-in-Residence, e.g. for Cargo), the Rust Innovation Lab (newest project: Josh), Rust Foundation Trusted Training, and supply-chain security engineering for crates.io. It also announced three staff departures in mid-2026.[^rf-media]
