# What happened
The Rust Foundation board approved an updated Rust trademark policy on Jan 23, 2025.[^rf-explained] It followed a draft circulated for final feedback in Nov 2024, which the Rust Project's Leadership Council had worked on with the Foundation.[^rust-blog-nov24][^slashdot-draft] The 2023 draft had drawn heavy criticism. The final policy says the marks cover only use in the context of the Rust language. It allows use without permission for non-commercial merchandise, unpaid community events, books, blogs and social accounts, and crate and repository names that signal Rust compatibility. The `rust-` and `cargo-` crate prefixes are no longer reserved.[^rf-explained][^rf-updates]

# Why it matters
Trademark became the main lever in several 2024–2026 open-source fights: WordPress (Automattic vs WP Engine), NATS (Synadia vs CNCF) and JavaScript (Deno vs Oracle). Rust shows the other path. A foundation-held mark was governed with the project's leadership, enforcement is left mainly to community reports, and the Foundation said it would not spend resources policing small creators.[^rf-explained]

# Outcome so far
No notable Rust trademark disputes were found between Feb 2025 and Oct 2026. The policy is a reference point for foundations that want to protect a name without alienating the community.
