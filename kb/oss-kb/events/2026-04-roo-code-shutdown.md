# What happened
On 2026-04-20 Roo Code said "we do not believe IDEs are the future of coding" and announced shutdown of the extension, Roo Code Cloud and Router on 2026-05-15 to focus on Roomote, a cloud agent working via Slack, GitHub and Linear; unused balances were refunded[^tns-roo]. The 24k-star repo was archived on 2026-05-15[^roo-gh].

# Why it matters
A popular Apache-2.0 tool vanished by business decision; signals the shift from IDE extensions to autonomous cloud agents.

# Outcome so far
Competitors (Kilo, Cline) published migration paths[^kilo-roo-migration]; community republish efforts exist but no dominant fork.
