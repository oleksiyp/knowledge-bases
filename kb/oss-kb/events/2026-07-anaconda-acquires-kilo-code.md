# What happened
Anaconda acquired Kilo (terms undisclosed), citing ~10T tokens orchestrated monthly and 3M+ developers, to offer governed multi-model agentic engineering to enterprises[^anaconda-kilo]. Kilo had raised $8M in Dec 2025[^cnbc-kilo].

# Why it matters
Consolidation among the Cline-lineage OSS agents (Roo shut down; Kilo acquired) within three months.

# Outcome so far
Kilo continues shipping (v7.8.3, 2026-10-01); Anaconda's post calls the code "source-available" while GitHub reports MIT — watch for license changes[^anaconda-kilo].
