# What happened
OpenAI announced on 2026-03-09 that it would acquire Promptfoo (founders Ian Webster and Michael D'Angelo; backers incl. Insight Partners and a16z), an open-source tool for LLM evals, red-teaming and static scanning used by 350k+ developers and 25%+ of the Fortune 500[^oai-promptfoo][^pf-blog][^cnbc-pf]. Promptfoo said it "will remain open source" and keep supporting all model providers[^pf-blog].

# Why it matters
LLMOps/eval tooling is consolidating into model labs and data platforms (Langfuse → ClickHouse in Jan 2026); a frontier lab now owns a widely used vendor-neutral eval harness, raising neutrality questions.

# Outcome so far
Promptfoo continues as open source per its stated commitment; long-term neutrality unproven.
