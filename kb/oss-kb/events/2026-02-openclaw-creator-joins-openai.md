# What happened
On 2026-02-14 Peter Steinberger announced he was joining OpenAI to build personal agents; Sam Altman said "OpenClaw will live in a foundation as an open source project that OpenAI will continue to support"[^oc-fortune][^oc-wiki].

# Why it matters
A frontier lab captured the leading OSS personal-agent project's creator and influence without an acquisition, while keeping the code MIT under foundation stewardship.

# Outcome so far
The promised foundation launched on 8 July 2026 as a US 501(c)(3) non-profit (executive director Dave Morin; first full-time team of ten; sponsors include OpenAI, GitHub, NVIDIA, Microsoft and Tencent), keeping the code MIT[^oc-foundation]. The project kept shipping at high cadence (OpenClaw 2.0, v2026.8.1, end of Aug 2026)[^oc-release-2] and grew to ~390k stars[^oc-wiki].
