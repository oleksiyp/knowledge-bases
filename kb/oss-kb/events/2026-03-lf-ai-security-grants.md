# What happened
$12.5M administered by Alpha-Omega and OpenSSF for "maintainer-centric AI security assistance", because maintainers face "an unprecedented influx of security findings".[^lf-12m]

# Why it matters
The first large pooled response by AI labs to the maintainer burden their own tools create.
