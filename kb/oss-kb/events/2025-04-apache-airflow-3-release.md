# What happened
Airflow 3.0.0 was released on 2025-04-22 with DAG versioning, a new React UI, the Edge Executor and a redesign targeting AI/ML and near-real-time workloads[^airflow-gh][^bdw-af3][^astro-news].

# Why it matters
Refuted the "Airflow is legacy" narrative pushed by newer orchestrators; enabled remote/multi-language task execution.

# Outcome so far
3.1 (2025-09-25), 3.2 (2026-04-07) and 3.3 (2026-07-06) followed on schedule; a Java SDK beta appeared in July 2026.
