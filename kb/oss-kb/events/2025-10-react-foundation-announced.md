# What happened
On 2025-10-07 the React team announced the React Foundation, with Seth Webster as executive director. It will run React's infrastructure, React Conf and ecosystem grants under a vendor-neutral board. Technical governance will be a separate structure set by contributors.[^rf-blog] The foundation officially launched on 2026-02-24, when Meta contributed the React project.[^wiki-react]

# Why it matters
It ends 12 years of React being formally a Meta project. It also gives commercial users (Vercel, Microsoft, Amazon, Expo) a formal seat, and gives the community protection against a single company changing course.[^rf-blog]

# Outcome so far
The legal transfer is done (Feb 2026). The design of the technical governance has not yet been verified as finalised.
