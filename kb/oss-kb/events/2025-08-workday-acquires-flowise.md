# What happened
Workday announced around Aug 14, 2025 that it was acquiring Flowise, the Apache-2.0 low-code AI agent builder with 42k+ GitHub stars, to speed up AI agents for its HR and finance customers. Terms were not disclosed.[^osfy-flowise][^yahoo-flowise][^diginomica-flowise] (Corrected in pass 2: date set from month start (2025-08-01) to the announcement, ~2025-08-14.)

# Why it matters
Enterprise SaaS vendors bought agent-builder teams to accelerate their own AI agents.

# Outcome so far
Within a year Flowise was sunset: code freeze 2026-07-29, archived Aug 2026, EOL 2026-08-31.[^flowise-sunset]
