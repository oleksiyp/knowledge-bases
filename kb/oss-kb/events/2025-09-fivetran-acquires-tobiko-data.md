# What happened
Fivetran acquired Tobiko Data (team from Airbnb, Apple, Netflix) to add SQLMesh's virtual environments, column-level lineage and multi-dialect SQL to its platform, while affirming partnerships with dbt Labs and Coalesce[^fivetran-tobiko][^bdw-tobiko].

# Why it matters
Fivetran bought the main open-source challenger to dbt one month before agreeing to merge with dbt Labs.

# Outcome so far
SQLMesh was donated to the Linux Foundation on 2026-03-25; releases continue (0.236.x)[^fivetran-tobiko].
