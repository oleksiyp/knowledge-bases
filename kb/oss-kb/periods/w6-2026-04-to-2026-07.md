# Net assessment

Strong for private COSS and for neutral standards. Bad for open-weight idealism, since Meta's exit made the open frontier mostly Chinese. Also bad for single-vendor open core, which hardened further (Cal.com, MinIO, Bitnami). "AI makes open code risky" first appeared as a rationale for closing code (Cal.com, NHS England).
