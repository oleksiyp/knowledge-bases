# E3 — 2022-10 → 2024-10

* [Deno 1.0 released](2020-05-deno-1-0.md) - Ryan Dahl's "Node done right" runtime reached 1.0 with secure-by-default permissions, built-in TypeScript and URL imports with no package.json; most of those bets were later softened toward Node compatibility.
* [Microsoft stops evolving Visual Basic .NET](2020-03-visual-basic-language-frozen.md) - On 2020-03-11 Microsoft said VB would run on .NET 5 but "we do not plan to evolve Visual Basic as a language", ending two decades of C#/VB co-evolution; the 2023 language strategy made VB "consumption-only".
* [WebAssembly becomes a W3C Recommendation](2019-12-webassembly-w3c-recommendation.md) - The W3C published WebAssembly Core 1.0 as an official web standard, the "fourth language of the web" after HTML, CSS and JavaScript.
* [Node.js 13.2 unflags ECMAScript modules](2019-11-node-esm-unflagged.md) - Node.js 13.2.0 made native ES modules loadable without a flag (via .mjs or "type":"module"), which began a CommonJS-to-ESM migration that took about five more years to become painless.
* [Mozilla, Fastly, Intel and Red Hat found the Bytecode Alliance](2019-11-bytecode-alliance-founded.md) - An industry alliance formed to build a secure-by-default WebAssembly runtime stack outside the browser (Wasmtime, Cranelift, WAMR, WASI); it became the steward of WASI and the component model.
* [C# 8 ships nullable reference types](2019-09-csharp-8-nullable-reference-types.md) - With .NET Core 3.0 on 2019-09-23, C# 8 made 'string' versus 'string?' a compile-time distinction for reference types: opt-in, warnings-only and erased at runtime. It was the first retrofit of null safety onto a top-5 managed language, and it became the default for new projects in .NET 6.
* [Facebook open-sources the Hermes JavaScript engine](2019-07-hermes-open-sourced.md) - At Chain React 2019 Facebook released Hermes, an MIT-licensed JS engine for React Native that compiles JavaScript to bytecode ahead of time instead of JIT-compiling it on the device.
* [Apple announces SwiftUI at WWDC 2019](2019-06-swiftui-announced.md) - On 2019-06-03 Apple unveiled SwiftUI, a declarative UI framework usable only from Swift. It made Swift the required language for Apple's future UI work. Adoption was slow and partial: years later many teams still wrapped SwiftUI in UIKit shells.
* [Google declares Android development "Kotlin-first"](2019-05-android-kotlin-first.md) - At Google I/O on 2019-05-07 Google said Android development would be increasingly Kotlin-first, with new Jetpack APIs offered first in Kotlin. This was the decisive platform endorsement that made Kotlin the default Android language.
* [Oracle–Eclipse trademark deal forces Jakarta EE off the javax namespace](2019-05-jakarta-ee-javax-namespace.md) - In May 2019 the Eclipse Foundation said its agreement with Oracle meant Jakarta EE could use the javax package namespace only 'as is', never evolve it. This forced the javax.* to jakarta.* rename in Jakarta EE 9 (Dec 2020), a break across the whole enterprise Java ecosystem.
* [Oracle ends free public Java 8 updates for commercial users](2019-01-oracle-java-8-public-updates-end.md) - Oracle's January 2019 Critical Patch Update (8u201/8u202) was the last Java 8 build free for commercial production use. From April 2019 Oracle JDK moved to the OTN licence, which requires a paid subscription for production use. The change set off a mass move to third-party OpenJDK builds.
