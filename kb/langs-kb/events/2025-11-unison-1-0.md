# What happened
On 25 November 2025 Unison Computing tagged release/1.0.0.[^unison-releases] The announcement presented 1.0 as the point where the language, distributed runtime and workflow had stabilized. Highlights: code is identified by hash and stored in a database, renames and branch switches are instant, there is native version control (projects, branches, PRs on Unison Share), Unison Cloud and "Bring Your Own Cloud" deployment, and ecosystem-wide type-based search. At launch Unison Share had 139,811+ published definitions from 1,300+ authors.[^unison-1-0] The press called it a "futuristic" debut.[^infoworld-unison] Releases 1.1–1.5 followed by October 2026, the last adding GADTs.[^unison-releases]

# Why it matters
It is the most complete real-world test of [content-addressed code](/ideas/tooling-and-ecosystem/content-addressed-code.md) and of algebraic effects (abilities) in a production-oriented language. Reception was friendly but repeated the long-standing objection that code outside text files breaks existing tools.[^hn-unison-1]
