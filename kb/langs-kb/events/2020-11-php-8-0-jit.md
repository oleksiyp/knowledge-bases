# What happened
PHP 8.0 shipped JIT compilation. The release page contrasts substantial synthetic benchmark gains with application workloads whose performance remained similar to PHP 7.4.[^announcement]

# Why it matters
**Interpretation:** shipping a JIT is an implementation milestone; the benefit depends on the workload. Synthetic arithmetic speedups should not be presented as equivalent web-application gains.
