# What happened
Bun 1.0 shipped on 2023-09-08.[^wiki-bun] It was positioned as a drop-in replacement for Node.js that folded a runtime, an npm-compatible package manager, a bundler, and a Jest-compatible test runner into one binary. It was written in Zig on Apple's JavaScriptCore (WebKit) engine rather than V8.[^bun-v1] The launch post made vendor benchmark claims: startup up to 4x faster than Node, 4x more HTTP requests per second, and tests 13x faster than Jest on Zod's suite. Windows support was "highly experimental", with only the runtime enabled.[^bun-v1]

# Why it matters
Bun made speed and "one tool instead of five" the axes of runtime competition. Node.js answered with faster releases, a built-in test runner and TypeScript stripping. Bun's Node-compatibility-first strategy, the opposite of Deno 1.0's clean break, got real adoption: 7.2M monthly downloads by October 2025.[^bun-joins-anthropic] Its business model never materialised. Oven was acquired by Anthropic with zero revenue in December 2025, and Bun was later ported from Zig to Rust.[^bun-joins-anthropic]
