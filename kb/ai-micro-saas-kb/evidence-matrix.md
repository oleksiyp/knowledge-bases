## Reading the gaps

This table is not a leaderboard. The core AI-built cases have less detailed distribution evidence than several older AI-powered products. Using the latter as comparators can suggest experiments, but it cannot establish that an AI-generated app will get the same results. Several platforms publish customer stories to sell development tools; selection bias is part of the evidence, not an incidental footnote.

The next research priority is not more large headline numbers. It is a matched set of recent small builders reporting source → activation → paid cohort → repeat use, including unsuccessful attempts. See [research gaps](/references/research-gaps.md).
