# Summary

The PSF runs CPython governance support, PyPI and community grants. Its Developers-in-Residence are funded by Alpha-Omega, Bloomberg, Meta (previously) and anonymous donors.[^psf-dir]

# Programs

- [PSF Developers-in-Residence](/programs/individuals/psf-developers-in-residence.md)

# 2025–2026 changes

- The PSF withdrew from a $1.5M US government grant over DEI-related conditions.[^psf-nsf-withdraw] It then received $1.5M from Anthropic in January 2026 for security work and core programs.[^psf-anthropic]
