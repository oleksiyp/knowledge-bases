# Summary

NIH funds biomedical research software through dedicated notices. The Office of Data Science Strategy (ODSS) runs a sustainable-software R03 and an RSE salary award (R50). Institutes run domain programs such as NCI's ITCR and BRAIN Initiative resource U24s.[^sg-rfa-od-26-034][^sg-rfa-od-24-011][^rfa-ca-27-021][^rfa-ns-27-001]

# Programs

- [Building Sustainable Software Tools for Open Science (R03)](/programs/research-software/nih-sustainable-software-r03.md): 2026 reissue forecast, not confirmed
- [RSE Award (R50)](/programs/research-software/nih-rse-award-r50.md): final due date 2026-12-04
- [NCI ITCR](/programs/research-software/nci-itcr.md): due 2026-10-19

# 2025–2026 changes

- NIH no longer funds foreign subawards or subcontracts unless the NOFO specifically allows them, which affects international software collaborations.[^rfa-ca-27-021]
- The ODSS R03 reissue (RFA-OD-26-034) has been in 'forecasted' status since February 2026.[^sg-rfa-od-26-034]
