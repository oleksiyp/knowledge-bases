# Summary

Sentry gave $750,000 to open source maintainers for 2025, its fifth consecutive year, routing half through thanks.dev and the rest to foundations, ecosystem funds and GitHub Sponsors.[^sentry-750k-2025] It launched the Open Source Pledge (≥$2,000 per developer per year), whose members have paid $7.4M+.[^osp-home]
