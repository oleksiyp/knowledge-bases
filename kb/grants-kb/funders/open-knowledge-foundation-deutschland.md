# Summary

Open Knowledge Foundation Deutschland e.V. runs the [Prototype Fund](/programs/oss-infrastructure/prototype-fund.md), with money from the German federal research ministry (BMFTR) administered through a project agency.[^okfde-ptf][^ptf-wiki] The fund backs individuals and small teams building open source software in data security and software infrastructure.[^ptf-dsee]

# Programs

- [Prototype Fund](/programs/oss-infrastructure/prototype-fund.md) — cohort 03 applications 1 Oct–30 Nov 2026.[^ptf-dsee]

# 2025–2026 changes

- New program edition with team amounts up to €95k and a second stage; focus areas data security and software infrastructure.[^ptf-dsee]
