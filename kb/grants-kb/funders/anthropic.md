# Summary

Anthropic supports software developers mostly through product access. Claude for Open Source gives up to 10,000 maintainers six months of Claude Max 20x.[^cfoss] Project Glasswing (April 2026) committed up to $100M in Claude Mythos Preview usage credits and $4M in donations to OSS security organizations: Alpha-Omega/OpenSSF $2.5M and Apache $1.5M.[^glasswing] Anthropic also runs AI for Science API credits[^afs-support] and the paid Anthropic Fellows research program.[^fellows-post]
