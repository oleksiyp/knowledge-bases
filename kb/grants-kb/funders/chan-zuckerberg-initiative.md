# Summary

CZI's EOSS program was the largest dedicated funder of open-source scientific software maintenance. Over six cycles it deployed $58M to 230+ projects.[^rp-os4s] The EOSS page now says the program is not accepting applications.[^czi-eoss]

# Programs

- [EOSS](/programs/research-software/czi-eoss.md): ended (final cycle LOIs October 2023)
- Successor: [Open Source for Science Fund](/programs/research-software/os4science-open-source-life-sciences.md), co-seeded by Biohub

# 2025–2026 changes

- In May 2026 Biohub and Wellcome seeded the $20M Open Source for Science Fund hosted by Renaissance Philanthropy, built on the EOSS design.[^rp-os4s]
