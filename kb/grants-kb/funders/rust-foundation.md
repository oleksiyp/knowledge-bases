# Summary

The Rust Foundation supports the Rust Project. It funded 21 fellows in 2024,[^rf-fellows-2024] and in 2026 launched the Maintainers Fund for long-term maintainer support.[^rfmf-launch]

# 2025–2026 changes

- RFC 3931 created the Rust Project Funding Team and the MiR program in June 2026.[^rfmf-launch] The first MiR cohort was announced on 26 August 2026, funded by Google, AWS, OpenAI and the Leadership Council.[^rust-mir-first]
