# Summary

OpenJS hosts Node.js and many JS projects. In September 2026 it launched the pooled Security Stewardship Program (bug bounties + paid maintainer security work).[^socket-openjs] Its Ecosystem Sustainability Program channels revenue from commercial EOL-support partners to projects.[^openjs-esp] Alpha-Omega granted OpenJS $580k in 2025.[^ao-recipients]
