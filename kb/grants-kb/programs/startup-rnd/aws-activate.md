# Summary

AWS Activate offers cloud credits: up to $5,000 for self-funded startups (Founders), up to $200,000 for startups backed by an Activate Provider (Portfolio), and invite-only AI credits above that[^aws-activate]. Decisions in about 5–10 business days[^aws-activate].

# Eligibility

- Pre-Series B, founded within last 10 years, AWS account on paid tier, new to Activate or requesting more than before[^aws-activate].

# What it funds

- AWS usage only.

# Amounts & terms

See amount_text[^aws-activate].

# How to apply

AWS Builder ID → select tier → startup details → link account[^aws-activate].
