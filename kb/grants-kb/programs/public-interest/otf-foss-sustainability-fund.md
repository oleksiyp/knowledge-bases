# Summary
The FOSS Sustainability Fund pays for maintainability, interoperability, reproducibility, security and resilience work on free and open-source software. The software must be a core dependency of internet-freedom technology or have many active users in repressive contexts.[^otf-fosssf] GitHub co-funds the current round.[^otf-fosssf] As of October 2026 the page says it is "not currently accepting applications". OTF's guidebook describes the call as annual.[^otf-fosssf][^otf-fosssf-guide]

# Eligibility
- The project must be a core dependency of internet-freedom tech, or have substantial active users in repressive environments.[^otf-fosssf]
- The guidebook asks for software released for at least 3 years, updates at least 4 times a year, active coding in the last 2 years, and a substantial active user base if the software is user-facing.[^otf-fosssf-guide] Dormant projects that are still widely used may qualify for revival.[^otf-fosssf]
- Applicants in OFAC-sanctioned countries, surveillance-tech developers and US-debarred entities cannot apply. Applicants must be able to undergo an independent audit.[^otf-fosssf]

# What it funds
- Maintenance, refactoring, security hardening, reproducible builds, interoperability and documentation. It funds the upkeep of existing software, not new features.[^otf-fosssf]

# Amounts & terms
- About $7,000/month for 6–24 months for individual maintainers, up to $400,000 over 24 months for larger ecosystem initiatives.[^otf-fosssf]
- The guidebook expects up to four projects of $150k–$400k for about 24 months.[^otf-fosssf-guide]
- Grantees can also get free security audits, documentation help and usability reviews from OTF Labs.[^otf-fosssf]

# How to apply
Two stages: a concept note, then an invited full proposal.[^otf-fosssf]

# Fit
- **Good fit if:** you maintain a mature library, protocol implementation or app that VPNs, secure messengers or circumvention tools depend on.
- **Poor fit if:** your project is new, has few users, or has no link to internet freedom. Try [NLnet](/programs/oss-infrastructure/) or Sovereign Tech-style funds instead.
