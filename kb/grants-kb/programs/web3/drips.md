# Summary
Drips is funding infrastructure rather than a funder: organisations create **Drip Lists** (up to 200 GitHub repos, addresses or other lists with percentage shares) and stream or split tokens to them, with funds propagating to declared dependencies.[^drips-gitcoin][^drips-docs] Ecosystems use it to run RetroPGF rounds with nomination, voting and on-chain payouts.[^drips-retro] In 2026 **Drips Wave** launched: recurring one-week contribution sprints where contributors earn Points converted to rewards; Stellar Wave 7 ran in July 2026.[^drips-wave]

# Eligibility
- Maintainers claim their GitHub repository on Drips to collect funds sent to it; Wave contributors work on maintainer-curated issues.[^drips-docs][^drips-wave]

# What it funds
- Open-source repositories and their dependencies; contributor work during Waves.[^drips-home]

# Amounts & terms
- Set by each funder or round; paid on-chain in crypto tokens. KYC requirements are set by round operators (not documented centrally).[^drips-retro]

# How to apply
- Claim your repo; watch for ecosystem RetroPGF rounds and Wave programs on drips.network.[^drips-wave]

# Track record
- Used for RetroPGF rounds by Filecoin, Optimism and other ecosystems (dedicated subdomains).[^drips-home]

# Fit
- **Good fit if:** you maintain a widely depended-upon OSS library and want passive dependency funding.
- **Poor fit if:** you need an upfront project grant.
