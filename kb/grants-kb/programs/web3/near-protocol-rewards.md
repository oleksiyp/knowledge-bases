# Summary
NEAR's funding page lists **Protocol Rewards** — "a transparent, metrics-based rewards system for NEAR projects that directly ties incentives to development activity and user adoption" — alongside DevHub grants (tooling), Potlock (public-goods donations and funding rounds) and Meta Pool grants.[^near-funding] Protocol Rewards offers up to $10K/month at launch stage, scoring GitHub commits, PRs, reviews and issues as part of the evaluation.[^npr]

# Eligibility
- NEAR projects with public GitHub repos and on-chain activity (Protocol Rewards).[^npr]

# What it funds
- Development activity and adoption of NEAR projects; DevHub funds tooling.[^near-funding]

# Amounts & terms
- Up to $10K/month (launch tier); program reports $200K+ total rewards to 20 active projects.[^npr]

# How to apply
- Register on nearprotocolrewards.com and connect repos; other programs via their own sites.[^npr][^near-funding]

# Deadlines
Rolling.

# Track record
- $200K+ rewards, 20 active projects (program site).[^npr]

# Fit
- **Good fit if:** you actively ship code on NEAR and want rewards proportional to activity.
- **Poor fit if:** you need a larger upfront grant.
