# Summary
Filecoin Foundation's devgrants repository offers **Open Grants** of up to $50,000 "to support novel ideas that advance the Filecoin ecosystem", submitted as GitHub issues; the RFP section currently says "Stay tuned!" (none open).[^ff-gh] Grants cover storage solutions, developer tooling and the Filecoin Virtual Machine, and funded work must be open source (the Foundation's grants page lists MIT/Apache-2.0 dual licensing).[^ff-grants] The related Protocol Labs Research **Open Research Grants** were paused in 2023; PL Research now funds only via occasional topic RFPs and awards through grants.protocol.ai.[^pl-pause][^pl-research-gh]

# Eligibility
- Any team or individual with an idea advancing the Filecoin ecosystem.[^ff-grants]

# What it funds
- Storage tooling, FVM, developer tools, integrations, documentation.[^ff-grants]

# Amounts & terms
- Up to $50K; open-source licensing (MIT + Apache-2.0) required.[^ff-grants]
- Payment currency/KYC: not documented in the repo README (unverified).[^ff-gh]

# How to apply
- Open a proposal issue using the Open Grant template in filecoin-project/devgrants; custom proposals to grants@fil.org.[^ff-gh]

# Deadlines
Rolling.

# Track record
- Active repository with 100+ open proposal issues.[^ff-gh]

# Fit
- **Good fit if:** you build OSS tooling for IPFS/Filecoin storage or FVM.
- **Poor fit if:** you need >$50K or academic research funding (PL open research grants paused).
