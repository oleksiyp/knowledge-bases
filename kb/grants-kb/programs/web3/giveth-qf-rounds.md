# Summary
Giveth is a crypto donation platform for public goods that runs quadratic-funding rounds, often with external sponsors providing the matching pool.[^giveth-docs] Its largest 2026 round, Ethereum Security QF (23 Apr – 14 May 2026), was funded by TheDAO Security Fund (500 ETH) plus Wintermute, Quantstamp and others, reaching 637.4 ETH matching; 134 projects were accepted from 250+ applications.[^giveth-qf][^etherworld-qf] Giveth also manages milestone payouts for TheDAO's Round Two.

# Eligibility
- Projects create a Giveth project page and must be verified/accepted into each round; eligibility criteria are set per round (EF set them for the security round).[^giveth-qf]

# What it funds
- Public goods across many causes; rounds can be thematic (security, ecosystem-specific).[^giveth-docs]

# Amounts & terms
- Matching distributed via QF on donations; paid on-chain in crypto.[^giveth-docs]

# How to apply
- Create a project on Giveth, get verified, and apply to the specific QF round when announced; mobilise donors.[^giveth-docs]

# Track record
- Ethereum Security QF: 3,934 unique donors, 13,805 donations, >$315K direct donations.[^giveth-qf]

# Fit
- **Good fit if:** you have a community of small donors and a public-goods project.
- **Poor fit if:** you need a large, predictable grant.
