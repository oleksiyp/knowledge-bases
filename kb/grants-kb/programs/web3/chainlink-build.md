# Summary
Chainlink BUILD is often listed among "web3 grants" but is not one: participating projects received enhanced access to Chainlink services and technical support and in return committed a percentage of their token supply to the Chainlink ecosystem (e.g. LINK stakers).[^cl-intro] On 26 June 2026 Chainlink Labs announced it was concluding existing BUILD arrangements and moving to commercial agreements paid in LINK or liquid assets, case by case; BUILD-related Chainlink Rewards claims ended 7 July 2026.[^cl-evo]

# Eligibility
- Early- and mid-stage projects integrating Chainlink, by agreement.[^cl-intro]

# What it funds
- Nothing in cash; it provides services and support in exchange for token commitments.[^cl-intro]

# Amounts & terms
- Not equity-free in the economic sense: it costs token supply or fees.[^cl-evo]

# How to apply
- Now only via bilateral commercial discussions with Chainlink Labs.[^cl-evo]

# Deadlines
None.

# Track record
- 80+ projects supported; ~$20M in project tokens distributed to LINK stakers.[^cl-evo]

# Fit
- **Good fit if:** you are a token project that needs Chainlink services and can pay in tokens/fees.
- **Poor fit if:** you want non-dilutive grant funding for software.
