# Summary
Brink supports open-source Bitcoin protocol development through two programs.[^brink-prog] **Grants** are year-long awards to established developers with a "track record of making high-quality, security-first contributions", focused on base-protocol security and stability but also Lightning/L2, scalability and usability; applicants are global.[^brink-prog] The **Fellowship** is a one-year, salaried program in Brink's London office pairing new engineers with senior Bitcoin Core contributors (relocation required; visa help case-by-case).[^brink-prog]

# Eligibility
- Grants: proven Bitcoin/related OSS contributions, public progress updates, independent work style.[^brink-prog]
- Fellowship: prior OSS contributions; able to relocate to London.[^brink-prog]

# What it funds
- Bitcoin Core review/testing, fuzzing, cryptography (incl. post-quantum research), Lightning.[^brink-home][^conduition]

# Amounts & terms
- Full-time funding for a year; amounts not published.[^brink-prog]

# How to apply
- Google Form applications linked from brink.dev/programs.[^brink-prog]

# Deadlines
Rolling.

# Track record
- Grantees include developers working on Bitcoin Core review, fuzz testing and post-quantum cryptography research.[^brink-home][^conduition]

# Fit
- **Good fit if:** you already contribute meaningfully to Bitcoin Core/Lightning and want full-time support.
- **Poor fit if:** you are building a Bitcoin app/business.
