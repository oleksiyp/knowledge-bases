# Summary
Zcash Community Grants (ZCG) is funded by the Zcash Dev Fund (ZIP-1014/1015/1016), which allocates 8% of mining rewards through November 2028; the program reports roughly 100,000 ZEC (≈$11M) available.[^zcg-site] A five-person community-elected committee funds independent teams doing "major ongoing development (or other work) for the public good of the Zcash ecosystem".[^zcg-site] Priority areas are wallets, SDKs, core infrastructure, interoperability, applications, ongoing services and education; there is an active RFP for Lightwalletd infrastructure.[^zcg-site]

# Eligibility
- Teams or individuals proposing public-good work for Zcash.[^zcg-site]

# What it funds
- Wallets, SDKs, infra, interop, education.[^zcg-site]

# Amounts & terms
- Scope-based; proposals are public on GitHub/forum. Payment/KYC specifics: see ZCG terms (not verified here).[^zcg-site]

# How to apply
- Submit a proposal on GitHub (or propose an RFP idea via form); discussed publicly on the forum.[^zcg-site][^zcg-forum]

# Deadlines
Rolling (committee meets regularly).

# Track record
- Ywallet, ZecHub, Free2z, Ledger integration, Zcash Shielded Assets.[^zcg-site]

# Fit
- **Good fit if:** you build privacy-preserving Zcash wallets, SDKs or infra in the open.
- **Poor fit if:** you are unwilling to work fully in public.
