# Summary
Retro Funding rewarded projects after the fact for measurable impact on the Optimism Superchain. In 2025 it ran algorithmic missions: **Dev Tooling** (up to 8M OP for compilers, libraries, debuggers used by onchain builders, scored from GitHub, npm, crates and onchain data, paid monthly Feb–Jul 2025) and **Onchain Builders** (up to 8M OP).[^op-devtool][^oso-s7] In January 2026 the Optimism Foundation announced that Retro Funding "will not run for at least the next 12 months" and that ~775M OP reserved for it may be reallocated.[^op-s9] An August 2026 governance vote reallocated tokens into a new Strategic Ecosystem Fund (reported).[^cryptonomist-op]

# Eligibility
- (When running) projects registered on Optimism Atlas; Dev Tooling required open-source code with a public GitHub repo and history of public commits.[^op-devtool]

# What it funds
- Historically: developer tooling, onchain apps, OP Stack contributions, governance — retroactively.[^op-devtool]

# Amounts & terms
- Paid in OP tokens; amounts determined by metrics-based algorithms.[^oso-s7]

# How to apply
- No applications accepted while paused.[^op-s9]

# Track record
- Cumulative commitments ≈81.4M OP before the pause (reported).[^cryptonomist-op]

# Fit
- **Good fit if:** you track it for a possible 2027 restart; your OSS dev tool is widely used by Superchain builders.
- **Poor fit if:** you need funding in 2026.
