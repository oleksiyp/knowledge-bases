# Summary

The Rust Foundation Maintainers Fund (RFMF) launched in June 2026. It provides "consistent, transparent, and long term support" for Rust Project maintainers.[^rfmf-launch] Its main instrument is the Maintainer in Residence (MiR) program, which funds existing project members to maintain the compiler, standard library, Cargo and other components. Shorter grants sit alongside it.[^rfmf-launch] The first cohort was announced on 26 August 2026, funded by $350,000 from Google, AWS, OpenAI and the Rust Project Leadership Council. It has four MiRs (one full-time, three half-time, working on rustup, Clippy, rustdoc, the compiler and Windows support) and two grant recipients.[^rust-mir-first]

# Eligibility

- Existing Rust Project members and maintainers.[^rfmf-launch]

# What it funds

- Code review, unblocking features, triage and mentoring on critical Rust components.[^rfmf-launch]

# Amounts & terms

- Full-time or half-time funded positions, plus grants. Amounts are not published.[^rust-mir-first]

# How to apply

- There is no public application form. The Rust Project Funding Team selects recipients with team leads and advisors, depending on available funding.[^rust-mir-first] Talk to your team lead.

# Deadlines

None published.

# Track record

- First cohort (August 2026): Gen Li, Alejandra González, Chris Denton and León Orell Valerian Liehr as MiRs, plus grants to Jonas Böttiger and Jason Newcomb.[^rust-mir-first]

# Fit

- **Good fit if** you are already a Rust Project maintainer.
- **Poor fit if** you work on a third-party crate. Look at [GitHub Sponsors](/programs/individuals/github-sponsors.md) or [thanks.dev](/programs/oss-infrastructure/thanks-dev.md).
