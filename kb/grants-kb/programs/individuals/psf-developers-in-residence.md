# Summary

The PSF's Developers-in-Residence are paid individuals who maintain core Python infrastructure, with each role funded by a sponsor.[^psf-dir] Current roles include Seth Larson (Security Developer-in-Residence, Alpha-Omega), Mike Fiedler (PyPI Safety & Security, Alpha-Omega), Petr Viktorin (CPython, Bloomberg) and Serhiy Storchaka (anonymous donor). Łukasz Langa previously held the Meta-funded CPython role for five years.[^psf-dir] In January 2026 Anthropic gave the PSF $1.5M, which supports the Developer-in-Residence program, PyPI security and community grants.[^psf-anthropic]

# Eligibility

- Hiring is through PSF job postings. In practice these roles go to established CPython or PyPI contributors.

# What it funds

- CPython triage and review, security response, and PyPI malware handling.[^psf-dir]

# Amounts & terms

- Compensation is not published.

# How to apply

- Watch PSF job postings. Organizations that want to fund a new role can contact sponsors@python.org.[^psf-dir]

# Deadlines

None; roles are opened ad hoc.

# Track record

- The program has grown from one role to a team covering CPython, security and PyPI safety.[^psf-anthropic]

# Fit

- **Good fit if** you are a core Python contributor looking for a sustained paid role.
- **Poor fit if** you are new to the Python core.
