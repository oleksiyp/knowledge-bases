# Summary

GitHub Accelerator was announced in November 2022 to help maintainers "make a full-time career in open source".[^gh-acc-first] The first cohort (2023) had 20 projects with 32 participants.[^gh-acc-first] The 2024 cohort focused on open-source AI. It funded 10–11 projects with $40,000 each in non-dilutive funding, plus a 10-week full-time virtual program.[^gh-acc-site][^gh-acc-2024-showcase] The site still shows the 2024 cohort, whose deadline was 5 March 2024, and no 2025 or 2026 cohort could be found.[^gh-acc-site] Treat it as inactive. GitHub's newer maintainer funding (for example the GitHub Secure Open Source Fund) is covered in the oss-infrastructure category.

# Eligibility

- Maintainers of open-source projects (AI-focused in 2024), able to commit full-time for the program.[^gh-acc-site]

# What it funds

- Maintainer time to build a sustainable path for their project, with mentorship.[^gh-acc-site]

# Amounts & terms

- $40,000 per project in 2024.[^gh-acc-site]

# How to apply

- No open call.
