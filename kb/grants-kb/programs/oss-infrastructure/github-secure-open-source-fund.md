# Summary

GitHub's Secure Open Source Fund pairs money with security education: each selected project receives $10,000 through GitHub Sponsors and its maintainers complete a 3-week security program (≈15 hours) with GitHub Security Lab, then 6- and 12-month check-ins.[^gh-sosf] Co-funders include Microsoft, Stripe, Shopify, Datadog and others; ecosystem partners include OpenSSF, Mozilla and OSI.[^gh-sosf] Through Session 4 (Aug 2026) it had funded 188 projects in 42 countries with $1.88M.[^gh-sosf-50] Applications are rolling and considered for upcoming sessions; Session 5 intake closed 24 August 2026.[^gh-sosf-50]

# Eligibility

- Current maintainer(s) of an open source project (team of up to 3), 18+, active GitHub profile, located in a GitHub Sponsors–supported region, not a GitHub employee.[^gh-sosf]
- Clear OSS licence and governance; demonstrated community traction/adoption.[^gh-sosf]

# What it funds

- Security improvements to the project: threat modelling, CodeQL/secret scanning adoption, fuzzing, vulnerability disclosure processes, dependency hygiene — agreed as milestones with GitHub Security Lab.[^gh-sosf]

# Amounts & terms

- $10,000 per project: $6,000 during the program, $2,000 at 6 months, $2,000 at 12 months.[^gh-sosf]
- Time commitment ≈20 hours total (15 h over 3 weeks + 2.5 h at each check-in).[^gh-sosf]

# How to apply

- Short application on the program page; applications are rolling and considered for all program sessions.[^gh-sosf]

# Track record

- Session 4: 50 projects, 71 maintainers, 22 countries, $500k+.[^gh-sosf-50]
- Cumulative to Aug 2026: 188 projects, 42 countries, $1.88M, 533 CVEs disclosed, 650+ exposed secrets resolved.[^gh-sosf-50]
- Participants include evcc, NixOS and Mockoon.[^evcc-sosf][^nixos-sosf][^mockoon-sosf]

# Fit

- Good fit if: you maintain a moderately to widely used project and want a quick, low-effort $10k plus structured security training.
- Poor fit if: you need salary-scale funding, or live outside GitHub Sponsors regions.
