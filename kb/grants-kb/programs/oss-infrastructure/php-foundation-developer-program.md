# Summary

The PHP Foundation funds PHP's development by contracting core developers. Each autumn it runs an application form; for 2026 it closed 30 October 2025 with hiring decisions by end of November and starts on 1 January 2026.[^php-apply-2026] Roles split time between bug fixing/triage (40%), strategic areas (30%), code review (20%) and RFCs/features (10%+); C and systems-programming expertise is required.[^php-apply-2026] In 2025 the Foundation spent ~$139k more than it raised to keep headcount, and in 2026 it also launched an Ecosystem Security Team.[^php-report-2025][^php-security-team]

# Eligibility

- Demonstrated php-src contributions, PHP extension experience, internals mailing-list participation.[^php-apply-2026]
- "Not a job for PHP developers or aspiring PHP developers."[^php-apply-2026]

# What it funds

- Contracted work on the PHP language runtime.[^php-apply-2026]

# Amounts & terms

- Not published; distributed/asynchronous.[^php-apply-2026]
