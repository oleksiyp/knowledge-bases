# Summary

Microsoft's FOSS Fund awards up to $12,500 each quarter, across one or more open source projects nominated and voted on by Microsoft employees who contribute to non-Microsoft OSS.[^ms-fossfund] It remains active: Fund 34 (June 2025, 13 projects), Fund 35 (Oct 2025, 9 projects), Fund 36 (March 2026, 14 projects).[^ms-fossfund]

# Eligibility

- Project used by Microsoft, OSI-approved licence, able to receive funds (GitHub Sponsors or similar), not owned by a Microsoft employee; DEI considered.[^ms-fossfund]

# What it funds

- Unrestricted donation.[^ms-fossfund]

# Amounts & terms

- Up to $12,500 per quarter in total.[^ms-fossfund]

# How to apply

- Not open to applications; enable GitHub Sponsors so employees can nominate you.[^ms-fossfund]

# Deadlines

| Date | Event |
|---|---|
| Quarterly | Nomination/vote cycles[^ms-fossfund] |

# Track record

- Recent recipients include Actix, aiohttp, Apache Solr, DocsGPT, pnpm.[^ms-fossfund]

# Fit

- Good fit if: Microsoft uses your project and you accept sponsorships.
- Poor fit if: you need a planned grant.
