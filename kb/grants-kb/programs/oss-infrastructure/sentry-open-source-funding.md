# Summary

Sentry has paid open source maintainers every year since 2021; for 2025 it gave **$750,000** (announced 6 January 2026).[^sentry-750k-2025] Recipients are chosen by dependency analysis rather than applications: $375k was distributed through thanks.dev, $250k as direct grants to foundations, $75k through Open Source Collective/ecosyste.ms ecosystem funds and $50k via GitHub Sponsors.[^sentry-750k-2025] Sentry also founded the [Open Source Pledge](/programs/oss-infrastructure/open-source-pledge.md).[^osp-home]

# Eligibility

- Projects in Sentry's dependency tree (for the thanks.dev share) or foundations Sentry chooses.[^sentry-750k-2025]

# What it funds

- Unrestricted support to maintainers and foundations.[^sentry-750k-2025]

# Amounts & terms

- Direct foundation grants in 2025 included Django Software Foundation $30,000, PSF $16,750, PostgreSQL $15,000, Rust Foundation $15,000.[^sentry-750k-2025]

# How to apply

- No application. Make sure your project can receive money: register on thanks.dev, enable GitHub Sponsors and/or add `funding.yml`.[^sentry-750k-2025]

- Poor fit if: you want to propose a project.
