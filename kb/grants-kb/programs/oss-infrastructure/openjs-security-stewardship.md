# Summary

Launched 25 September 2026, the OpenJS Security Stewardship Program pools money from companies to pay for Node.js security: half goes to bug bounties for security researchers and half to maintainers doing triage, patching, backporting and security releases.[^socket-openjs] It responds to a 4.6× jump in monthly HackerOne reports to Node.js in February 2026 and to Node.js pausing its bug bounty after external funding ended in April 2026.[^socket-openjs] OpenJS acts as CVE Numbering Authority for disclosure.[^socket-openjs] Separately, the OpenJS Ecosystem Sustainability Program (ESP) shares revenue from commercial end-of-life support partners (HeroDevs, NodeSource, TuxCare) with projects.[^openjs-esp]

# Eligibility

- Security researchers: report Node.js vulnerabilities via HackerOne.[^socket-openjs]
- Maintainers: Node.js project maintainers doing security work (initial focus).[^socket-openjs]
- Companies: contact OpenJS to join as funders.[^socket-openjs]

# What it funds

- Bug bounties; paid maintainer time for triage, fixes, backports and releases; CVE coordination.[^socket-openjs]

# Amounts & terms

# How to apply

- No open grant application; participation through Node.js security team roles and HackerOne.[^socket-openjs]
