# Open-source infrastructure & security grants

* [Alpha-Omega Grants (OpenSSF / Linux Foundation)](alpha-omega-grants.md) - Security grants (typically $50,000–$100,000; up to ~$800k for foundations) for OSI-licensed projects, foundations and ecosystem services; quarterly open intake — Q4 2026 submissions 1–31 Oct 2026.
* [Bloomberg FOSS Contributor Fund](bloomberg-foss-fund.md) - Quarterly Bloomberg employee vote awarding up to three $10,000 grants per cycle to OSS projects, paid via Open Source Collective; latest disbursements Dec 2025 (Let's Encrypt, pURL).
* [Cloudflare Project Alexandria (OSS credits)](cloudflare-project-alexandria.md) - Recurring annual Cloudflare credits/plan upgrades (Pro/Business/Enterprise, Workers, Pages, R2, Zero Trust) for non-profit open source projects; rolling applications, no one-year cut-off.
* [Datadog for Open Source Projects](datadog-oss-program.md) - Free Datadog observability/security accounts for non-commercial OSS projects ≥1 year old with ≥5 regular contributors and maintainers from ≥2 companies; case-by-case rolling applications.
* [Open Source Collective / ecosyste.ms Ecosystem Funds](ecosystem-funds.md) - Pooled per-ecosystem funds (Python, Rust, JavaScript, Django, PHP, …) run by Open Source Collective and ecosyste.ms that pay 100% of balances monthly to critical projects selected by dependency data; no application.
* [Fastly Fast Forward](fastly-fast-forward.md) - Free Fastly CDN and edge-compute services for open source projects and the nonprofits that support them (since 2014; serves Python, Rust, Ruby, Linux Foundation, Apache); rolling applications.
* [FLOSS/fund (Zerodha)](floss-fund.md) - $1M/year fund from Indian broker Zerodha giving $10,000–$100,000 grants to FOSS projects worldwide, applied for via a funding.json manifest and reviewed quarterly; a fresh $1M allocated for 2026.
* [Gem Fellowship (gem.coop / Contributed Systems)](gem-fellowship.md) - $100,000/year (committed for three years by Sidekiq maker Contributed Systems) in $2,500–$25,000 grants to individual Ruby developers maintaining open source Ruby tools; 2027 applications open 1 Dec 2026 for the month of December.
* [GitHub Secure Open Source Fund](github-secure-open-source-fund.md) - $10,000 per project plus a 3-week security education program and GitHub Security Lab milestones for maintainers of widely used OSS (worldwide in GitHub Sponsors regions); rolling applications across sessions — Session 5 closed 24 Aug 2026.
* [Google Open Source Peer Bonus](google-open-source-peer-bonus.md) - Small cash "token of appreciation" awards to external OSS contributors nominated by Google employees; last public winners announcement June 2024 — 2025–26 status unverified.
* [Horizon Europe — Open Internet Stack calls (Cluster 4)](horizon-europe-open-internet-stack.md) - Large EU consortium grants (e.g. €7M–€10.25M per project, 100% funding) for mature open-source sovereign internet solutions; 2026 topic HORIZON-CL4-2026-04-DATA-02 closed 15 Apr 2026; future topics depend on the 2027 work programme.
* [Microsoft FOSS Fund](microsoft-foss-fund.md) - Quarterly employee-nominated awards of up to $12,500 (split across one or more projects) to OSI-licensed projects Microsoft uses; active (Fund 36, March 2026); no external application.
* [Mozilla Open Source Support (MOSS)](mozilla-moss.md) - Mozilla's former OSS grant program (Foundational Technology, Mission Partners, Secure Open Source tracks); on indefinite hiatus since Mozilla's 2020 restructuring — not accepting applications.
* [NLnet CodeSupply (software supply-chain security pilot)](nlnet-codesupply.md) - Horizon Europe pilot run by NLnet offering €5,000–€50,000 grants (€400k pot) for FOSS work on software supply-chain metadata — origin, licensing, vulnerabilities, quality; first call closes 3 Nov 2026.
* [NLnet NGI Zero Commons Fund](nlnet-ngi-zero-commons.md) - EU NGI fund (€21.6M through 2027) that gave €5,000–€50,000+ grants for open internet commons; its 13th and final call closed 1 June 2026 — no new applications (successor is Restack).
* [NLnet Restack (Open Internet Stack cascade fund)](nlnet-restack.md) - EU Horizon Europe–funded successor to NGI Zero run by NLnet — €5,000–€50,000 R&D grants (scalable) for free/open internet-stack technology, open to individuals and organisations worldwide; first call closes 3 Nov 2026.
* [Open Source Pledge](open-source-pledge.md) - Companies pledge ≥$2,000 per employed developer per year to OSS maintainers/foundations of their choice; $7.4M+ paid to date — a demand-side commitment, not an application program.
* [OpenJS Foundation Security Stewardship Program](openjs-security-stewardship.md) - Pooled, industry-funded program (launched Sept 2026) that splits contributions between bug bounties for researchers and paid triage/patching/release work by Node.js maintainers; invite/sponsor-based, not an open grant call.
* [PHP Foundation core developer contracts](php-foundation-developer-program.md) - The PHP Foundation contracts part-/full-time developers to work on php-src (C), selected via an annual autumn application (last closed 30 Oct 2025 for 2026 starts); funded by corporate/individual donations plus Sovereign Tech Fund–commissioned work.
* [Prototype Fund (Germany)](prototype-fund.md) - German federal (BMFTR) funding via Open Knowledge Foundation Germany for individuals and small teams building public-interest open source software — up to €47,500 per person / €95,000 per team for 6 months plus optional second stage; cohort 03 applications 1 Oct–30 Nov 2026.
* [PSF Grants Program (Python Software Foundation)](psf-grants-program.md) - Small grants for Python community events (conferences ≤$2,000, workshops ≤$1,500) — not development work; paused Aug 2025 after hitting its cap, reopened as a limited $90k round with applications 4–25 Aug 2026.
* [Sentry Open Source Funding](sentry-open-source-funding.md) - Sentry's annual $750,000 payout (2025, fifth year running) to the OSS it depends on — mostly via thanks.dev dependency analysis plus foundations, ecosyste.ms funds and GitHub Sponsors; no application.
* [Sovereign Tech Fellowship](sovereign-tech-fellowship.md) - Paid fellowships (freelance contracts worldwide or German employment at €64k–€82k/yr FTE) for maintainers, community managers and technical writers of critical OSS; 2026 round closed 6 April 2026, next round not yet announced.
* [Sovereign Tech Fund (Sovereign Tech Agency)](sovereign-tech-fund.md) - German federal investment program commissioning maintenance and security work on open digital base technologies (minimum €50,000 of work per application); rolling applications, open in October 2026.
* [Sovereign Tech Resilience](sovereign-tech-resilience.md) - In-kind security services (audits, tech-debt work, memory-safety migration, post-quantum readiness, supply-chain hardening, Cyber Resilience Act compliance, bug & fix bounties) at no cost for critical FOSS projects; relaunched 28 Sept 2026, rolling applications.
* [Sovereign Tech Standards (pilot)](sovereign-tech-standards.md) - Pilot paying OSS maintainers €4,800–€5,200/month for ~10 h/week of participation in IETF, W3C or ISO standards work; up to 10 maintainers, June 2026–June 2027; applications closed 19 May 2026.
* [Spotify FOSS Fund](spotify-foss-fund.md) - Annual Spotify donations (since 2022) to independent OSS projects it relies on — 2025 round (announced Jan 2026) gave FFmpeg €30k, Xiph.Org €25k, Mock Service Worker €15k; no public application.
* [thanks.dev (dependency-based donations)](thanks-dev.md) - Platform where companies set a monthly budget that is auto-distributed across their dependency tree (up to 3 levels); maintainers claim payouts by registering — Sentry routed $375k through it for 2025.
* [Tidelift (Sonar) — paid maintainer "lifter" program](tidelift.md) - Commercial subscription model (acquired by Sonar, announced Dec 2024) that pays maintainers monthly to meet security/maintenance standards for packages its customers use — an income alternative to grants, not a grant.
