# Summary

Datadog offers free accounts to open source projects that need observability and security monitoring for the infrastructure that runs the project (CI, websites, registries).[^dd-oss] The Apache Software Foundation (since 2016) and the PSF (since 2017) are long-time users.[^dd-partner] Datadog is also a funding partner of the [GitHub Secure Open Source Fund](/programs/oss-infrastructure/github-secure-open-source-fund.md).[^gh-sosf]

# Eligibility

- Non-commercial, approved OSS licence, ≥1 year old, ≥5 regular contributors, ≥2 maintainers employed by different companies; monitoring must cover project infrastructure, not instances of the software.[^dd-oss]

# What it funds

- In-kind Datadog usage.[^dd-oss]
