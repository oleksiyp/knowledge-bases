# Summary

Project Alexandria (announced 27 September 2024) is Cloudflare's open source program, offering recurring annual credits: upgrades to Pro/Business/Enterprise plans (WAF, rules, security analytics), higher Workers and Pages limits, extra R2 storage for builds/artifacts, and Zero Trust with Remote Browser Isolation.[^cf-alexandria-blog] Cloudflare leadership says projects aren't removed after one year.[^cf-knecht] Useful for cutting hosting/CDN/package-distribution costs.

# Eligibility

- Recognised OSS licence and operating on a non-profit basis aligned with the project's mission.[^cf-alexandria-blog]

# What it funds

- Cloudflare services only (no cash).[^cf-alexandria-blog]

# Amounts & terms

- Tailored per project; annual recurring credits.[^cf-alexandria-blog]

# How to apply

- Form on the Project Alexandria page.[^cf-alexandria-lp]
