# Summary

Codex for Open Source is OpenAI's in-kind support package for open-source maintainers. It includes six months of ChatGPT Pro with Codex, API credits from the **$1M Codex Open Source Fund**, and conditional access to Codex Security for repositories that need deeper security coverage.[^codex-oss] OpenAI announced it in early March 2026.[^winbuzzer-codex] Reviews are rolling, and you can apply for your own project or nominate another maintainer.[^codex-oss] Third-party coverage reports API credits of up to $25,000 per project and an informal bar of about 1,000+ GitHub stars. OpenAI's own page only says "core maintainers of widely used public projects".[^winbuzzer-codex][^codex-oss]

# Eligibility

- Core maintainers of widely used public projects. OpenAI invites projects that do not meet the criteria but matter to the ecosystem to apply and explain why.[^codex-oss]
- Applicants must accept the program terms.[^codex-oss-terms]

# What it funds

- ChatGPT Pro with Codex for coding, triage, review and maintainer workflows.[^codex-oss]
- API credits for projects that use Codex in PR review, maintainer automation, release workflows or other core OSS work.[^codex-oss]
- Conditional access to Codex Security.[^codex-oss]
- No cash. The credits cannot pay for maintainer time.

# Amounts & terms

- Six months of ChatGPT Pro. API credits come from the $1M fund, with amounts set per project.[^codex-oss]
- Some participants in the community thread reported account and invitation problems, so keep your confirmation emails.[^codex-forum]

# How to apply

- Fill in the short form at openai.com/form/codex-for-oss.[^codex-oss-form]
- Highly critical projects can also be pulled into the Daybreak "Patch the Planet" effort, where Trail of Bits engineers help turn findings into merged fixes.[^patch-planet]

# Track record

- Projects in the related Patch the Planet effort include cURL and Python. Participating projects there receive ChatGPT Pro, conditional Codex Security and API credits.[^patch-planet]

# Fit

- **Good fit if:** you maintain a popular or critical OSS project and want to automate triage, review or security scanning.
- **Poor fit if:** you need cash for your time, or your project is small or new with few users.
