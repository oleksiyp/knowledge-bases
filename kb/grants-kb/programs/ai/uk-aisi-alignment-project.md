# Summary

The Alignment Project is a coalition fund led by UK AISI. Partners include the Canadian and Australian AI safety institutes, OpenAI, Microsoft, AWS, Anthropic, Schmidt Sciences and Renaissance Philanthropy.[^ap-site] It funds research to stop advanced AI from behaving dangerously, with grants of **£50k–£1M** plus dedicated cloud compute, API credits, optional VC investment and AISI mentorship.[^ap-site] Round 1, announced on 19 February 2026, gave **£27M to 60 projects** chosen from 800+ applications across 42 countries.[^ap-blog] The February post said a new round would open in the summer. The project site now says AISI is "unlikely to run a similar program in 2026" but expects to run other academic grant programmes.[^ap-blog][^ap-site]

# Eligibility

# What it funds
