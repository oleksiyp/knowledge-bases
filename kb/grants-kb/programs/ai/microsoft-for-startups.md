# Summary

Microsoft for Startups offers **up to $150,000 in Azure credits**, which can be spent on Azure AI services and models, along with developer tools and go-to-market help.[^ms-startups] Credits are released in tiers. Third-party guides report about $1k for email-verified sign-ups and up to $5k after business verification. The six-figure tiers are mostly reached through Microsoft's Investor Network or accelerator partners.[^ms-startups-cfs]

# Eligibility

- For-profit startups building a software product. The higher tiers need investor affiliation.[^ms-startups-cfs]

# What it funds

- Azure services, including Azure AI and OpenAI models, plus GitHub and Microsoft 365 perks.[^ms-startups][^ms-startups-cfs]

# Amounts & terms

- Up to $150k in credits.[^ms-startups]

# How to apply

- Apply through the online portal.[^ms-startups]
