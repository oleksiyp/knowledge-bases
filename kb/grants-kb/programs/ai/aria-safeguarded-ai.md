# Summary

ARIA's **£59M Safeguarded AI** programme has shifted toward showing that fleets of AI agents can model and verify critical cyber and cyber-physical systems.[^aria-sga-funding] Its current open call is **Safeguarded AI: Cybersecurity**, a £20M call that tests whether AI-enabled formal methods can make high-assurance cyber defence practical at scale.[^aria-iuk] It funds **3–6 Blue Teams at about £2.5–3.5M each** to build production-grade, security-critical software components whose key security properties are backed by machine-checked proofs. Teams work in 8-week sprints against red teams.[^aria-iuk][^aria-sga-funding] Proposals are rolling and reviewed quarterly. The current cycle opened on 4 September 2026 and the **next cut-off is 31 October 2026, 14:00 GMT**, with notification on 30 November.[^aria-sga-funding] Earlier TA1 tooling calls are closed, and the TA2 Machine Learning call was cancelled in a strategic pivot.[^aria-sga-funding]

# Eligibility

- Academia, industry and non-profits. Teams should combine security engineering, formal methods and AI-assisted workflows.[^aria-sga-funding]

# What it funds

- Verified, production-grade security software built with AI-assisted proof tooling. Verified open-source components are a natural fit.[^aria-sga-cyber-cfp]

# Amounts & terms

- See amount_text. ARIA funding is equity-free, and IP terms are set in ARIA's contracts.[^aria-sga-cyber-cfp]

# How to apply

- Apply through ARIA's grant platform. Read the CFP PDF (20 May 2026, v1.0).[^aria-sga-cyber-cfp][^aria-sga-funding]
