# Source principle

Werner and Le-Brun's companion guide argues for replacing routine approval gates with operating boundaries. It advocates cross-functional teams, central platforms that support local action, and authority backed by trust. Assigning responsibility while retaining all meaningful control is described as artificial ownership.[^ownership]

# Practical interpretation

The following decision record is an original template for applying the principle:

| Field | Question to answer |
|---|---|
| Decision | What specific action may this team take? |
| Owner | Who makes the final call? |
| Scope | Which customers, systems, and budget are included? |
| Constraints | Which limits must remain satisfied? |
| Escalation | Which condition requires a named additional decision-maker? |
| Review | When will the result and boundaries be reconsidered? |

# Illustrative example

An onboarding team can change help text and test its ordering within an agreed experiment scope. A change to the billing contract has a different owner. Record both decisions before the pilot so the team can distinguish a permitted action from a handoff.
