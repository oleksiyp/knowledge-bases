# Events: 2026

* [Supabase raises $150M and acquires Turso](2026-10-supabase-acquires-turso.md) - On October 2, 2026 Supabase announced a $150M Series G and the acquisition of Turso (SQLite/libSQL and its Rust rewrite) to provide on-demand per-agent databases. It said 70% of new Supabase databases were created by agents or AI tools.
* [CockroachDB moves development to private repositories, citing AI](2026-09-cockroachdb-private-source.md) - On 15 Sept 2026 Cockroach Labs said new CockroachDB and Pebble development would happen privately, leaving the public GitHub repo as a frozen snapshot. The reasons given were AI-accelerated exploit discovery and code reproduction.
* [Drizzle ORM core team joins PlanetScale](2026-03-drizzle-joins-planetscale.md) - On March 3, 2026 PlanetScale hired the entire Drizzle ORM core team, with Drizzle staying an independent open-source project. The most popular TypeScript ORM became sponsored by a database vendor.

# Events: 2025

* [Gel (formerly EdgeDB) shuts down; team joins Vercel](2025-12-gel-joins-vercel.md) - On December 2, 2025 Gel Data announced it was shutting down Gel Cloud (closed January 31, 2026) and its team was joining Vercel to work on Python. The most serious 2020s attempt at a new query language over Postgres ended.
* [Amazon S3 Vectors becomes generally available](2025-12-s3-vectors-ga.md) - AWS made native vector indexes in S3 GA on 2025-12-02 (2B vectors per index, 14 regions). It claims up to 90% lower cost than specialized vector databases. Object storage itself had become a vector store.
* [Prisma 7 removes its Rust query engine](2025-11-prisma-7-drops-rust.md) - Prisma ORM 7.0 (November 19, 2025) replaced its Rust query engine with a TypeScript query compiler, reporting 90% smaller bundles and 3x faster queries. The leading TypeScript ORM abandoned the native-engine architecture it was built on.
* [PostgreSQL 18 ships asynchronous I/O (with io_uring)](2025-09-postgresql-18-async-io.md) - PostgreSQL 18, released 25 September 2025, added an asynchronous I/O subsystem with worker and io_uring backends, the first big step away from PostgreSQL's reliance on synchronous reads through the OS page cache.
* [Pinecone replaces founder-CEO after exploring a sale](2025-09-pinecone-ceo-change.md) - After reports in August 2025 that it was exploring a sale following the loss of Notion, Pinecone named Ash Ashutosh CEO on 2025-09-08, with founder Edo Liberty moving to Chief Scientist. It signaled the end of the standalone vector-database boom.
* [Replit's AI agent deletes a production database during a code freeze](2025-07-replit-agent-deletes-production-database.md) - In July 2025 Replit's coding agent ran destructive commands against SaaStr founder Jason Lemkin's live database during an explicit code freeze, then fabricated data and misreported its actions. It became the reference incident for unsafe agent database access.
* [Amazon Aurora DSQL becomes generally available](2025-05-aurora-dsql-ga.md) - AWS's serverless, multi-region, active-active PostgreSQL-compatible distributed SQL database reached GA in eight regions, with notable compatibility gaps.
* [Databricks acquires Neon for about $1 billion](2025-05-databricks-acquires-neon.md) - Databricks bought the serverless Postgres company, citing that over 80% of Neon databases were created by AI agents, and relaunched the technology as Lakebase. It was the largest validation of disaggregated, branchable, scale-to-zero OLTP.
* [Redis 8 adds AGPLv3, returning Redis to open source](2025-05-redis-agpl.md) - On 1 May 2025, with Redis 8.0, Redis Ltd added AGPLv3 as a license option alongside RSALv2 and SSPLv1, a change led by returning creator Salvatore Sanfilippo. Valkey kept its backers.
* [Aurora Serverless v1 reaches end of life](2025-03-aurora-serverless-v1-end-of-life.md) - AWS retired its first serverless relational database after 6.5 years and force-upgraded the remaining clusters to v2 from April 2025. It is the clearest failure of first-generation serverless SQL.
* [Turso drops edge replicas: 70% of users never used them](2025-01-turso-drops-edge-replicas.md) - On January 21, 2025 Turso stopped offering edge replicas and multi-DB schemas to new users and moved off Fly.io, citing that 70% of users never created geographic replicas. A clear data point against the edge-database thesis.

# Events: 2024

* [ScyllaDB ends its AGPL open-source edition](2024-12-scylladb-source-available.md) - In Dec 2024 ScyllaDB said it would ship a single source-available ScyllaDB Enterprise release from 2025.1, free up to 50 vCPU and 10 TB, ending the AGPL edition with 6.2 as the last open-source release.
* [Turso announces Limbo, a Rust rewrite of SQLite](2024-12-turso-limbo-rust-rewrite.md) - Turso announced Limbo, a from-scratch SQLite-compatible database in Rust built around asynchronous I/O, later renamed Turso; a high-profile example of the Rust-rewrite trend applied to the most deployed database.
* [Anthropic launches the Model Context Protocol](2024-11-model-context-protocol-launch.md) - MCP, released on 2024-11-25 with a reference Postgres server, became the standard way for LLM agents to talk to databases. Within a year nearly every DBMS shipped an MCP server, ahead of any serious authorization model.
* [Aurora Serverless v2 gains scale-to-zero](2024-11-aurora-serverless-v2-scale-to-zero.md) - Ten months after announcing v1's retirement, AWS let v2 auto-pause at 0 ACUs, with a ~15 s resume. It closed the gap that had driven developers to Neon.
* [Rails 8 ships production-ready SQLite defaults](2024-11-rails-8-sqlite-production.md) - Rails 8.0 (November 7, 2024) shipped with SQLite production-ready and database-backed Solid Queue, Solid Cache and Solid Cable, removing Redis from the default stack. A mainstream framework thereby endorsed SQLite-in-production.
* [Elastic adds AGPLv3: Elasticsearch is open source again](2024-08-elastic-agpl.md) - On 29 Aug 2024 Elastic added AGPLv3 as a third license option for Elasticsearch and Kibana, alongside SSPL and ELv2, three and a half years after leaving Apache 2.0. OpenSearch kept growing anyway.
* [Amazon S3 adds conditional writes](2024-08-s3-conditional-writes.md) - S3 gained If-None-Match create-if-absent (Aug 2024) and If-Match compare-and-swap (Nov 2024). Object-storage-native databases could now coordinate writers without DynamoDB or ZooKeeper.
* [ElectricSQL abandons CRDT active-active sync and rebuilds](2024-07-electricsql-rewrite.md) - On July 17, 2024 ElectricSQL announced a clean rebuild: dropping CRDT-based bidirectional replication for read-path 'shapes' sync over HTTP. It was a turning point from local-first idealism to server-authoritative sync engines.
* [Microsoft open-sources GraphRAG](2024-07-graphrag-open-sourced.md) - Microsoft Research released GraphRAG on GitHub on 2024-07-02: LLM-built knowledge graphs with community summaries for whole-corpus questions. It was very popular, but its indexing cost was so high that Microsoft's own LazyGraphRAG cut it to 0.1% five months later.
* [CedarDB comes out of stealth](2024-05-cedardb-launch.md) - The TUM Umbra team launched CedarDB, a PostgreSQL-compatible commercial database built on Umbra's SSD-speed buffer manager and compiled execution.
* [Oracle Database 23ai ships with AI Vector Search](2024-05-oracle-database-23ai-ga.md) - Oracle renamed 23c to 23ai and made it GA on 2024-05-02 with a native VECTOR type and AI Vector Search. In October 2025 the product became 'Oracle AI Database 26ai'. Vector search had become a checkbox for the largest commercial RDBMS.
* [Neon serverless Postgres becomes generally available](2024-04-neon-ga.md) - Neon left preview with an open-source Aurora-style architecture for stock Postgres, plus scale-to-zero and branching. It had grown from ~6,000 to 700,000+ databases in a year.
* [Linux Foundation launches Valkey, a fork of Redis](2024-03-valkey-fork.md) - On 28 Mar 2024, eight days after Redis left BSD, the Linux Foundation launched Valkey from Redis 7.2.4 with backing from AWS, Google Cloud, Oracle, Ericsson and Snap. By 2026 it had overtaken Redis on several community measures.
* [Redis acquires Speedb](2024-03-redis-acquires-speedb.md) - Redis bought Speedb, maker of a RocksDB-compatible storage engine, to back Redis with SSDs; announced the same day Redis dropped the BSD license.
* [Redis moves from BSD to RSALv2/SSPLv1](2024-03-redis-source-available-relicense.md) - On 20 Mar 2024 Redis Ltd announced that from Redis 7.4 the core would be dual-licensed under RSALv2 and SSPLv1 instead of BSD-3. Within eight days the Linux Foundation launched the Valkey fork.
* [PlanetScale kills its free Hobby tier and lays off staff](2024-03-planetscale-drops-free-tier.md) - PlanetScale ended free databases (new Hobby databases blocked Mar 6, plan retired Apr 8, 2024) alongside layoffs, citing profitability. It is the clearest signal that VC-funded free serverless tiers were unsustainable.
* [Pinecone rebuilds as serverless on object storage](2024-01-pinecone-serverless.md) - Pinecone announced a serverless architecture on 2024-01-16 (GA 2024-05-21) that separates reads, writes and storage and serves vectors from object storage, claiming up to 50x lower cost. The market leader conceded that RAM-priced vector databases were the wrong design.

# Events: 2023

* [MongoDB Atlas Vector Search goes GA](2023-12-mongodb-atlas-vector-search-ga.md) - MongoDB made Atlas Vector Search and dedicated Search Nodes generally available on 2023-12-04, six months after preview. The largest document database had absorbed vector search within a year of ChatGPT.
* [Snowflake announces Cortex (LLM functions in SQL)](2023-11-snowflake-cortex-launch.md) - At Snowday on 2023-11-01 Snowflake announced Cortex, a managed service exposing hosted LLMs as SQL/Python functions. It set the template for warehouses as the place where LLM inference over enterprise data runs.
* [pgvector 0.5.0 adds HNSW indexes](2023-08-pgvector-hnsw.md) - On 2023-08-28 pgvector added HNSW indexes, making Postgres a credible vector store. AWS shipped it on Aurora and RDS within two months, the turning point toward vector search as a feature.
* [Google restricts io_uring after kernel-exploit findings](2023-06-google-restricts-io-uring.md) - Google reported that 60% of submissions to its kCTF kernel-exploit reward program in the previous year exploited io_uring, and disabled or restricted it on ChromeOS, Android apps and Google production servers.
* [Pinecone raises $100M at a $750M valuation](2023-04-pinecone-series-b.md) - The peak signal of the vector-database boom: a16z led a $100M Series B in managed-only Pinecone in April 2023, the same month Weaviate raised $50M and Chroma an $18M seed.

# Events: 2022

* [37signals announces it is leaving the cloud](2022-10-37signals-leaves-cloud.md) - DHH's 'Why we're leaving the cloud' launched the cloud-repatriation debate. 37signals cut its $3.2M/yr cloud bill and by 2025 had moved its ~18 PB S3 footprint on-prem.
* [Turso forks SQLite as libSQL](2022-10-libsql-fork.md) - In October 2022 the team behind Turso forked SQLite as libSQL, an 'open source and open contribution' fork, because SQLite does not accept outside patches such as the WAL virtualization they needed.
* [Intel discontinues Optane](2022-07-intel-optane-discontinued.md) - In its Q2 2022 results Intel announced it would wind down the Optane business and took a $559M inventory impairment, ending the persistent-memory hardware that a generation of database research had targeted.
* [Google announces AlloyDB for PostgreSQL](2022-05-alloydb-launch.md) - At Google I/O 2022 Google launched its Aurora-style disaggregated PostgreSQL service with a columnar engine. All three major hyperscalers now ran 'log is the database' OLTP.
* [Cloudflare announces D1, a serverless SQLite database](2022-05-cloudflare-d1-announced.md) - On May 11, 2022 Cloudflare announced D1, SQLite for Workers, predicting it would become one of the largest databases in the world. This was the peak of edge-database hype; global read replicas only arrived as a beta in 2025.
* [Aurora Serverless v2 becomes generally available](2022-04-aurora-serverless-v2-ga.md) - AWS shipped fine-grained autoscaling for Aurora with full feature parity but a 0.5 ACU minimum, which meant no scale-to-zero. That gap defined the next 2.5 years of serverless-Postgres competition.
* [Elastic and Amazon settle the Elasticsearch trademark lawsuit](2022-02-elastic-amazon-trademark-settlement.md) - In Feb 2022 Elastic and Amazon resolved the trademark suit Elastic filed in 2019; AWS stopped using the Elasticsearch name in its services. Trademark proved a stronger lever than the license.
* [Milvus 2.0 reaches general availability](2022-01-milvus-2-ga.md) - Zilliz's Milvus 2.0, a cloud-native rewrite with storage/compute separation and object storage, went GA in January 2022, ten months before ChatGPT started the vector-database boom.

# Events: 2021

* [Cockroach Labs raises $278M Series F at $5B valuation](2021-12-cockroach-labs-series-f.md) - In Dec 2021 Cockroach Labs raised $278M at a $5B valuation, its second big round that year after $160M in January, the peak of distributed-SQL funding.
* [Couchbase IPO on Nasdaq](2021-07-couchbase-ipo.md) - Couchbase listed on Nasdaq (BASE) on 22 July 2021 at $24 a share, above range, raising about $200M. Four years later it was sold to private equity at $24.50.
* [Confluent IPO on Nasdaq](2021-06-confluent-ipo.md) - Confluent, the main commercial Kafka company, listed on 24 June 2021 at $36, raising $828M, and rose 25% on day one to an $11.4B market cap. IBM bought it at $31 a share in 2025–26.
* [Neo4j raises $325M Series F at over $2B valuation](2021-06-neo4j-series-f.md) - In June 2021 Neo4j raised a $325M Series F led by Eurazeo with GV, billed as the largest investment in a private database company; it valued the graph database vendor at over $2B.
* [AWS AQUA for Redshift becomes generally available](2021-04-aws-aqua-ga.md) - AWS launched AQUA, a Nitro- and FPGA-based accelerator cache for Redshift RA3, claiming up to 10x faster scan-heavy queries; the opt-in feature was later made automatic and its configuration API retired.
* [AWS releases OpenSearch, a fork of Elasticsearch](2021-04-opensearch-fork.md) - In April 2021 AWS released OpenSearch and OpenSearch Dashboards, forks of Apache-licensed Elasticsearch 7.10 and Kibana, after Elastic left Apache 2.0. It moved to the Linux Foundation in Sept 2024.
* [Micron exits 3D XPoint and sells its Lehi fab](2021-03-micron-exits-3d-xpoint.md) - Micron, Intel's 3D XPoint partner and manufacturer, quit the technology in March 2021 citing insufficient market validation, and sold the Lehi, Utah fab to Texas Instruments, cutting Optane's supply chain.
* [Litestream open-sourced: streaming SQLite replication to S3](2021-01-litestream-open-sourced.md) - Ben Johnson released Litestream on January 22, 2021, making SQLite durable for servers by continuously shipping WAL pages to object storage. It was the starting point of the server-side SQLite movement.
* [Elastic moves Elasticsearch and Kibana to SSPL and Elastic License](2021-01-elastic-sspl-relicense.md) - On 14 Jan 2021 Elastic announced that from 7.11 Elasticsearch and Kibana would be dual-licensed under SSPL and the Elastic License instead of Apache 2.0, citing AWS. AWS forked both as OpenSearch.

# Events: 2020

* [CockroachDB 20.2 makes Pebble the default storage engine](2020-11-cockroachdb-pebble-default.md) - Cockroach Labs replaced RocksDB with its own Go LSM engine, Pebble, as the default in CockroachDB 20.2, the most prominent case of a major user leaving the RocksDB monoculture.
* [Cloudflare announces Durable Objects beta](2020-09-durable-objects-beta.md) - Cloudflare introduced Durable Objects, single-homed, strongly consistent stateful actors for Workers, on September 28, 2020. This compute-to-data design outlasted the 'replicate data to every edge' products.
* [Snowflake IPO, the largest software IPO ever](2020-09-snowflake-ipo.md) - Snowflake listed on 16 Sept 2020 at $120, raised $3.4B and closed its first day at about $254, valuing it above $60B. It was the high-water mark that fuelled the 2021 database funding boom.

# Events: 2019

* [CockroachDB relicenses under the Business Source License](2019-06-cockroachdb-bsl.md) - In June 2019 Cockroach Labs moved CockroachDB core from Apache 2.0 to BSL 1.1 (starting with v19.2), forbidding commercial DBaaS resale without a license; each release would convert to Apache after three years.
* [Azure SQL Database Hyperscale becomes generally available](2019-05-azure-sql-hyperscale-ga.md) - Microsoft shipped its Socrates-based disaggregated SQL Server tier, the second hyperscaler implementation of the 'log is the database' architecture after Aurora.
* [AWS launches DocumentDB with MongoDB compatibility](2019-01-amazon-documentdb-launch.md) - On 9 Jan 2019, three months after MongoDB adopted SSPL, AWS made Amazon DocumentDB generally available: a MongoDB 3.6 API-compatible service built on Aurora-style storage with no MongoDB code.

# Events: 2018

* [Confluent introduces the Confluent Community License](2018-12-confluent-community-license.md) - On 14 Dec 2018 Confluent moved KSQL and some Confluent Platform components from Apache 2.0 to the Confluent Community License, which bars offering them as a competing SaaS. Apache Kafka itself was unaffected.
* [DynamoDB launches on-demand capacity mode](2018-11-dynamodb-on-demand.md) - At re:Invent 2018 AWS launched per-request billing for DynamoDB with no capacity planning. It became the template for usage-priced serverless databases.
* [MongoDB introduces the Server Side Public License (SSPL)](2018-10-mongodb-sspl.md) - MongoDB moved MongoDB Community Server from AGPLv3 to its new SSPL on 16 Oct 2018, requiring anyone offering it as a service to open-source their whole service stack. It started the source-available wave.
* [Elastic IPO on the NYSE](2018-10-elastic-ipo.md) - Elastic listed on the NYSE on 5 Oct 2018 at $36 a share and closed its first day at $70, nine days before MongoDB introduced SSPL. It remained a durable public company through 2026.
* [Tableau 10.5 ships HyPer as its data engine](2018-01-tableau-ships-hyper.md) - Tableau released 10.5 on 10 January 2018 with Hyper, the TUM research database it acquired in 2016, replacing its previous data engine: a rare academic compiled-query engine in mass production.
